# 01 - Standard Model from the sphere: warped-throat sources

These papers back the warped-localisation idea in STILL_TO_DO, which is the next thing to try if Job 4b hits the rank-1 wall. It's Akitti's own picture from X (Aug 22-23, 2026; see AKITTI_LINK_POST.md, Problem 3). Every entry was checked on INSPIRE. The PDFs are kept here and in C:\Users\Akitt\Grok\pdf\ and don't go to GitHub.

- Gherghetta & Pomarol, "Bulk fields and supersymmetry in a slice of AdS", Nucl. Phys. B 586 (2000) 141-162, arXiv:hep-ph/0003129, doi:10.1016/S0550-3213(00)00392-8. File: NPB586_141_Gherghetta_Pomarol_bulk_fields_slice_of_AdS.pdf. Derives the bulk-fermion zero-mode profiles f(c) in Randall-Sundrum. Fermions with c > 1/2 sit near the UV end and have exponentially small values at the IR end.
- Huber & Shafi, "Fermion masses, mixings and proton decay in a Randall-Sundrum model", Phys. Lett. B 498 (2001) 256-262, arXiv:hep-ph/0010195, doi:10.1016/S0370-2693(00)01399-X. File: PLB498_256_Huber_Shafi_RS_fermion_masses_mixings.pdf. Gets the quark mass and mixing hierarchies from O(1) bulk masses c.
- Agashe, Perez & Soni, "Flavor structure of warped extra dimension models", Phys. Rev. D 71 (2005) 016002, arXiv:hep-ph/0408134, doi:10.1103/PhysRevD.71.016002. File: PRD71_016002_Agashe_Perez_Soni_warped_flavor_structure.pdf. This is RS flavour anarchy: random O(1) 5D Yukawas give V_ij ~ f_Qi/f_Qj, so V_ub ~ V_us V_cb (Venus's estimate in STILL_TO_DO).
