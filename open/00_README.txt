What this is
------------
A working list of still-open Magnetohydrodynamics problems, written for the hive
(spectral toy, incompressible mode="mhd" plus the new cmhd bones).

How to read
-----------
Each item has a name, one concept sentence (the shape), the math object in LaTeX,
why it is still open, and one thing a spectral code can plot. No proofs.

01_open_problems.txt  — the list
02_papers.txt         — arXiv / survey pointers (not a PDF dump; grab later if wanted)
03_hive_map.txt       — which of these sit on the live solver vs parked
