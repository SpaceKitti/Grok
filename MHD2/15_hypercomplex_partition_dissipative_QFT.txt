### 1. Complete mathematical apparatus extracted from the paper

**Hypercomplex algebra and field.**  
Let \(j\) be the hypercomplex unit satisfying the idempotent relations that generate the algebra (the precise multiplication table is fixed by the prior construction [1]; the essential feature used here is the existence of a pair of complementary projectors). A hypercomplex scalar field is written
\[
\Omega=\Phi+j\Psi,
\]
where \(\Phi,\Psi\) are ordinary complex fields. The hypercomplex Hermitian conjugation is compatible with the algebra so that the quadratic form remains positive in the stable domain.

**Euclidean action and path integral.**  
The imaginary-time formulation proceeds from the dissipative Lagrangian density of [1]. After Wick rotation the quadratic operator for the Fourier modes \(\tilde{\Omega}_{n,\mathbf{p}}\) has eigenvalues
\[
\lambda_{n,\mathbf{p}}=\omega_n-i\mu_s\pm\sqrt{E_{\mathbf{p}}^2+m_{\rm eff}^2},
\]
where \(\omega_n=2\pi nT\) are Matsubara frequencies, \(\mu_s\) is the chemical-potential shift induced by the algebra, and the *effective mass*
\[
m_{\rm eff}^2=m^2-\frac{\gamma^2}{4}
\]
encodes the dissipative parameter \(\gamma\). Stability requires \(\operatorname{Re}\lambda_{n,\mathbf{p}}>0\) throughout the thermal domain \(\mu<m_{\rm eff}\).

**Idempotent decomposition of the partition function.**  
The Gaussian functional integral factors under the idempotent projectors of the hypercomplex algebra. The resulting hypercomplex partition function satisfies
\[
\ln Z_H=\ln Z_J+J\ln Z_J
\]
(with \(J\) the algebraic dual generator). Explicitly the thermal piece is
\[
\ln Z_{{\rm th},H}=V\int\frac{d^3\mathbf{p}}{(2\pi)^3}\Biggl[\ln\bigl(1-e^{-\beta(E-\mu)}\bigr)+J\ln\bigl(1-e^{-\beta(E+\mu)}e^{i\beta\gamma/2}\bigr)\Biggr],
\]
where \(E=\sqrt{\mathbf{p}^2+m_{\rm eff}^2}\). The second sector carries a nontrivial thermal phase \(e^{i\beta\gamma/2}\) generated by dissipation.

**Series expansion (Bose representation).**  
Expanding the logarithms yields the standard Matsubara sum that can be rewritten via the integral representation of the modified Bessel functions:
\[
\ln Z_{{\rm th},H}=\frac{V m_{\rm eff}^2}{2\pi^2\beta}\sum_{k=1}^\infty\frac1k\Biggl[\cosh\Bigl(k\beta\mu\cos\frac{k\beta\gamma}{2}\Bigr)\pm i\sinh\Bigl(k\beta\mu\sin\frac{k\beta\gamma}{2}\Bigr)\Biggr]K_2(k\beta m_{\rm eff})
\]
(up to the precise index structure of the Bessel functions that follows from the three-dimensional momentum integral; the paper’s intermediate form with \(K_{k^2}\) is an equivalent intermediate expression before the standard reduction).

**Thermodynamic observables.**  
All standard quantities follow by differentiation while preserving the hypercomplex structure:

- Pressure:
\[
P_H=-\frac1{\beta V}\ln Z_H,\qquad
\operatorname{Re}P_H=\frac1{\pi^2\beta^2}\sum_k k m_{\rm eff}^2 K_2(k\beta m_{\rm eff})\cosh\Bigl(k\beta\mu\cos\frac{k\beta\gamma}{2}\Bigr),
\]
\[
\operatorname{Im}_J P_H=\pm\frac1{\pi^2\beta^2}\sum_k k m_{\rm eff}^2 K_2(k\beta m_{\rm eff})\sinh\Bigl(k\beta\mu\sin\frac{k\beta\gamma}{2}\Bigr).
\]

- Charge density:
\[
n_H=\frac1{\beta V}\Bigl(\frac{\partial\ln Z_H}{\partial\mu}\Bigr)_{\beta,\gamma}
\]
(identical hyperbolic structure).

- Energy density:
\[
\varepsilon_H=-\frac{\partial\ln Z_H}{\partial\beta}
\]
(containing the usual combination of \(K_1\) and \(K_2\) terms plus the explicit \(\gamma\)-dependent phase factors).

- Entropy density follows from the Euler relation \(s_H=(\varepsilon_H+P_H)/T\).

The vacuum contribution \(\ln Z_{\rm vac}=V\int\frac{d^3p}{(2\pi)^3}E_{\mathbf{p}}\) is ultraviolet divergent and is renormalised independently of the thermal sector (standard counter-term subtraction).

**Vanishing-dissipation limit and perturbative hierarchy.**  
As \(\gamma\to0\) one recovers \(m_{\rm eff}\to m\) and the hybrid (\(J\)) sector collapses, reproducing the ordinary relativistic charged Bose gas. At finite but small \(\gamma\) the paper demonstrates a distinctive hierarchy: dissipative corrections first appear at linear order in the *complementary phase sector* (the \(J\)-component), while corrections to the ordinary real thermodynamic quantities (\(P,\varepsilon,n\)) enter only at \(\mathcal{O}(\gamma^2)\) and higher. This is a direct algebraic consequence of the idempotent decomposition.

```python
import numpy as np
from scipy.special import kn   # modified Bessel K_nu
from functools import partial

# --- Physical constants (paper defaults; adjustable) ---
hbar = c = kB = 1.0
m    = 1.0          # bare mass
gamma = 0.15        # dissipative parameter
mu   = 0.3          # chemical potential
T    = 0.5          # temperature
beta = 1.0 / T
V    = 1.0          # volume (set to 1 for densities)

m_eff2 = m**2 - gamma**2 / 4
m_eff  = np.sqrt(m_eff2) if m_eff2 > 0 else 0.0
assert mu < m_eff, "Outside stable thermal domain"

def thermal_lnZ_series(beta, mu, gamma, m_eff, n_terms=40):
    """
    Hypercomplex thermal contribution (paper expansion).
    Returns (Re lnZ / V, Im_J lnZ / V)
    """
    s_re = 0.0
    s_im = 0.0
    pre  = m_eff**2 / (2 * np.pi**2 * beta)
    for k in range(1, n_terms+1):
        arg = k * beta * m_eff
        K2  = kn(2, arg)          # standard reduction of the momentum integral
        phase = k * beta * gamma / 2
        cosh_term = np.cosh(k * beta * mu * np.cos(phase))
        sinh_term = np.sinh(k * beta * mu * np.sin(phase))
        s_re += (1.0/k) * cosh_term * K2
        s_im += (1.0/k) * sinh_term * K2
    return pre * s_re, pre * s_im

def pressure(beta, mu, gamma, m_eff):
    lnZ_re, lnZ_im = thermal_lnZ_series(beta, mu, gamma, m_eff)
    P_re = - (1.0 / beta) * lnZ_re
    P_im = - (1.0 / beta) * lnZ_im   # J-component
    return P_re, P_im

def charge_density(beta, mu, gamma, m_eff, dmu=1e-5):
    """Numerical derivative of lnZ w.r.t. mu"""
    lnZp_re, lnZp_im = thermal_lnZ_series(beta, mu+dmu, gamma, m_eff)
    lnZm_re, lnZm_im = thermal_lnZ_series(beta, mu-dmu, gamma, m_eff)
    n_re = (1.0/beta) * (lnZp_re - lnZm_re) / (2*dmu)
    n_im = (1.0/beta) * (lnZp_im - lnZm_im) / (2*dmu)
    return n_re, n_im

# Example evaluation
P_re, P_im = pressure(beta, mu, gamma, m_eff)
n_re, n_im = charge_density(beta, mu, gamma, m_eff)
print(f"Re P = {P_re:.6e},  J-Im P = {P_im:.6e}")
print(f"Re n = {n_re:.6e},  J-Im n = {n_im:.6e}")

# Perturbative hierarchy diagnostic
def hierarchy_ratio(gamma_vals):
    ratios = []
    for g in gamma_vals:
        me = np.sqrt(m**2 - g**2/4)
        Pre0, _ = pressure(beta, mu, 0.0, m)
        Pre, Pim = pressure(beta, mu, g, me)
        ratios.append( (abs(Pim)/abs(Pre0), abs(Pre-Pre0)/abs(Pre0)) )
    return ratios

g_scan = np.linspace(0.01, 0.3, 12)
print("gamma | phase-sector / real0 | real-correction / real0")
for g, (r_phase, r_real) in zip(g_scan, hierarchy_ratio(g_scan)):
    print(f"{g:.3f} | {r_phase:.3e} | {r_real:.3e}")
```
