### 1. Complete mathematical apparatus extracted from the paper

**Kogut–Susskind Hamiltonian (pure SU(\(N\)) Yang–Mills).**  
\[
H = \frac{g^2}{2}\sum_\ell E_\ell^2 + \frac{1}{2g^2a^2}\sum_p\tilde{\mathcal{P}}_p,
\]  
where the magnetic term is the (negative) plaquette operator
\[
\tilde{\mathcal{P}}_p = -\operatorname{Tr}\bigl(U_{\ell_1}U_{\ell_2}U_{\ell_3}U_{\ell_4}\bigr)
\]  
and the link operators satisfy the fundamental commutation relations
\[
[E_a,U]=UT_a,\qquad [U,E_a]=T_aU,\qquad [E_a,E_b]=if^{abc}E_c.
\]

**Irrep / reduced electric basis.**  
Physical (Gauss-law) states are labelled by  
- an irrep \(R_\ell\) on every link \(\ell\),  
- a singlet multiplicity index \(g_v\) at every vertex \(v\) that resolves the fusion  
  \(R_{\ell_1}\otimes R_{\ell_2}\otimes\dots\to\mathbf{1}\).  

A local plaquette configuration is the core state
\[
s=(l_1,l_2,l_3,l_4;g_1,g_2,g_3,g_4)
\]  
together with passive control irreps \(c\) on the remaining links incident on the four vertices. Truncation is performed by a uniform electric-Casimir cutoff \(B\) (examples: \(B=6\) retains \(\mathbf{1},\mathbf{3},\overline{\mathbf{3}},\mathbf{8}\); \(B=9\) additionally retains \(\mathbf{6},\overline{\mathbf{6}}\)).

**Exact factorization of the plaquette matrix element.**  
\[
\langle t|\tilde{\mathcal{P}}_p|s\rangle
=\Biggl(\prod_{k=1}^4\frac{\dim R_{t\ell_k}}{\dim R_{s\ell_k}}\Biggr)
\Biggl(\prod_{v=1}^4 S_v\Biggr).
\]  
Each site factor admits the expansion
\[
S_v=\sum_{\sigma,r,r',u,u',\vec{c}}\phi_\sigma\,
\langle\mathbf{1},g_R;R,r\mid S,u;C,\vec{c}\rangle
\langle\mathbf{1},g_{R'};R',r'\mid S',u';C,\vec{c}\rangle
\]  
(with Condon–Shortley phase \(\phi_\sigma\) and a fixed spatial ordering of Clebsch–Gordan coefficients). Magnitudes factor as
\[
|\langle t|\tilde{\mathcal{P}}_p|s\rangle|=w_1w_2w_3w_4,\qquad
\sigma_{st}=\prod_v\sigma_v,
\]  
and the forward/reverse symmetry
\[
w_{\rm fwd}(s,c,t)=w_{\rm rev}(t,c,s),\qquad
\sigma_{\rm fwd}(s,c,t)=\sigma_{\rm rev}(t,c,s)
\]  
allows storage of only the forward tables.

**Block-encoding LCU.**  
Write \(H=H_E+H_B\). The magnetic block encoding is the LCU unitary
\[
U_{\rm LCU}=\operatorname{PREP}\cdot\operatorname{SELECT}\cdot\operatorname{PREP}^\dagger
\]  
with subnormalization \(\beta=g^2(\alpha_E+\alpha_B)\). The single-plaquette oracle \(U_p\) realises
\[
\langle0|_aU_p|0\rangle_a=\frac{\tilde{\mathcal{P}}_p}{\alpha_p},\qquad
\alpha_p=\max_s\sum_t|\langle t|\tilde{\mathcal{P}}_p|s\rangle|.
\]  
At the working truncations one obtains the concrete values
\[
\alpha_p(B=6)=86,\qquad\alpha_p(B=9)=5652.
\]

**Classical precomputation pipeline.**  
1. Enumerate all admissible site factors via Clebsch–Gordan tables (pcyclebsch) and convert magnitudes into rotation angles.  
2. For every source link-core \(\lambda=(l_1,l_4)\) enumerate the reachable target cores \((\lambda',d)\) together with weights \(\hat{w}_{\lambda\lambda'}\) and multiplicities.  
3. Partition control patterns into equivalence classes \(\tilde{q}_v\) that produce identical site factors; store the compact ADDR map.  
4. Build sparse unary-iteration QROM tables (proposal table size \(\sim1200\) rows at \(B=6\)).

**Quantum oracles.**

- Programmed \(R_y(2\theta)\) rotations with angle register \(a\):

import numpy as np
from itertools import product
from scipy.special import factorial  # for multiplicity bookkeeping

# --- Toy SU(2) catalogue for rapid prototyping (paper is SU(3); replace by full CG tables) ---
IRREPS = {0: 1, 1: 2, 2: 3}          # j -> 2j+1 dimension
CASIMIR = {0: 0.0, 1: 0.75, 2: 2.0}  # j(j+1)

def dim(R):
    return IRREPS[R]

def site_factor_toy(R_in, R_out, g_in, g_out, controls, max_B=2):
    """
    Extremely simplified site factor (replace by full Clebsch–Gordan sum of the paper).
    Returns (magnitude, phase_sign).
    """
    if max(CASIMIR[R_in], CASIMIR[R_out]) > max_B:
        return 0.0, 1
    # toy fusion weight ~ sqrt(dim_in * dim_out) / (sum dim controls + 1)
    w = np.sqrt(dim(R_in) * dim(R_out)) / (1 + sum(dim(c) for c in controls))
    sign = 1 if (g_in + g_out) % 2 == 0 else -1
    return w, sign

def precompute_proposal_table(B=1, max_links=2):
    """
    Classical precomputation of the sparse proposal table (paper Sec. 3–4).
    Returns list of (source_core, target_core, weight, direction).
    """
    table = []
    for l1, l4 in product(range(B+1), repeat=2):
        for lp1, lp4 in product(range(B+1), repeat=2):
            w = np.sqrt(dim(lp1)*dim(lp4)/(dim(l1)*dim(l4) + 1e-12))
            if w > 1e-8:
                table.append(((l1, l4), (lp1, lp4), w, 0))  # direction bit
                table.append(((lp1, lp4), (l1, l4), w, 1))  # reverse
    return table

def alpha_p_estimate(B=1, n_samples=5000):

    Monte-Carlo estimate of the subnormalization alpha_p = max_s sum_t |h_st|.

        s = 0.0
        for src, tgt, w, d in table:
            if src == (core[0], core[3]):
                s += w**4   # four site factors
        max_sum = max(max_sum, s)
    return max_sum

from scipy.linalg import expm

def block_encoded_walk(alpha_E, alpha_B, alpha_f, g2, a=1.0):
    """Toy 2-site matrix model of the full LCU walk (replace by circuit simulator)."""
    HE = np.diag([0.0, 1.0, 2.0])          # electric Casimirs
    HB = np.array([[0, 0.3, 0], [0.3, 0, 0.4], [0, 0.4, 0]])  # plaquette toy
    Hf = np.array([[0.1, 0.2, 0], [0.2, 0.1, 0.15], [0, 0.15, 0.2]])  # fermion hop
    H = g2*alpha_E*HE + (1/(g2*a**2))*alpha_B*HB + alpha_f*Hf
    beta = g2*alpha_E + (1/(g2*a**2))*alpha_B + alpha_f
    return H/beta, beta

def quench_evolution(H_norm, beta, t_list, state0):
    """Exact diagonalisation of the normalised Hamiltonian for validation."""
    evol = []
    for t in t_list:
        U = expm(-1j * beta * H_norm * t)
        evol.append(U @ state0)
    return np.array(evol)

def programmed_phase(a, b=8):

def goldberg_hexa_shell(n, resolution=32):
