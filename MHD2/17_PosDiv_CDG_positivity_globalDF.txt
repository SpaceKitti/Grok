### 1. Complete mathematical apparatus (paper equations, definitions, theorems)

**Ideal MHD system (compressible, conservative form)**  
\[
\partial_t\mathbf{U}+\sum_{\ell=1}^d\partial_{x_\ell}\mathbf{F}_\ell(\mathbf{U})=0,
\]  
where  
\[
\mathbf{U}=(\rho,\mathbf{m},\mathbf{B},E)^\top\in\mathbb{R}^8,
\quad
\mathbf{m}=\rho\mathbf{u},\quad
E=\rho e+\tfrac12\rho|\mathbf{u}|^2+\tfrac12|\mathbf{B}|^2,
\]  
and the fluxes are  
\[
\mathbf{F}_\ell(\mathbf{U})=\begin{pmatrix}
m_\ell\\
m_\ell\mathbf{u}-B_\ell\mathbf{B}+p_{\rm tot}\mathbf{e}_\ell\\
u_\ell\mathbf{B}-B_\ell\mathbf{u}\\
u_\ell(E+p_{\rm tot})-B_\ell(\mathbf{u}\cdot\mathbf{B})
\end{pmatrix},
\quad
p_{\rm tot}=p+\tfrac12|\mathbf{B}|^2.
\]  
The algebraic admissible set is the open convex cone  
\[
\mathcal{G}=\bigl\{\mathbf{U}:\rho>0,\quad\mathcal{E}(\mathbf{U}):=E-\tfrac12\bigl(|\mathbf{m}|^2/\rho+|\mathbf{B}|^2\bigr)>0\bigr\}.
\]  
The differential constraint is the globally divergence-free condition  
\[
\nabla\cdot\mathbf{B}=\sum_{\ell=1}^d\partial_{x_\ell}B_\ell=0.
\]

**Geometric quasi-linearization (GQL)**  
The nonlinear set \(\mathcal{G}\) is equivalent to an infinite family of linear half-spaces:  
\[
\mathcal{G}_*=\bigl\{\mathbf{U}:\mathbf{U}\cdot\mathbf{n}_1>0,\quad\mathbf{U}\cdot\mathbf{n}^*+\tfrac12|\mathbf{B}^*|^2>0\ \forall\mathbf{u}^*,\mathbf{B}^*\in\mathbb{R}^3\bigr\},
\]  
with  
\[
\mathbf{n}_1=(1,0,0,0,0,0,0,0)^\top,
\quad
\mathbf{n}^*=\bigl(\tfrac12|\mathbf{u}^*|^2,-\mathbf{u}^*,-\mathbf{B}^*,1\bigr)^\top.
\]  
Lemma (paper): \(\mathbf{U}\in\mathcal{G}\) if and only if there exists a supporting hyperplane \(\mathbf{n}\) such that  
\[
\mathbf{n}\cdot(\mathbf{U}-\mathbf{V})\ge0\quad\text{and}\quad\mathbf{n}\cdot\bigl(\mathbf{F}_\ell(\mathbf{U})-\mathbf{F}_\ell(\mathbf{V})\bigr)\ge0
\]  
for all \(\mathbf{V}\in\mathcal{G}\). This converts every nonlinear positivity constraint into a linear flux inequality that can be controlled under the global DF condition.

**Central DG framework on overlapping meshes**  
Primal mesh \(\mathcal{K}_h^C\) and dual mesh \(\mathcal{K}_h^D\). The non-magnetic variables \(\mathbf{R}=(\rho,\mathbf{m},E)^\top\) and the magnetic variables \(\mathbf{Q}=\mathbf{B}\) are evolved separately. The standard CDG update for a test function \(\phi\) on a primal cell \(K\) reads  
\[
\int_K\mathbf{U}_h^{n+1}\phi\,dx=\int_K\mathbf{U}_h^n\phi\,dx-\Delta t\int_K\mathbf{F}(\mathbf{U}_D^n)\cdot\nabla\phi\,dx+\int_K\tau(\mathbf{U}_D^n-\mathbf{U}_C^n)\phi\,dx,
\]  
where \(\tau=\max(\tau_x,\tau_y)\) is a local dissipation parameter. Global DF is enforced by reconstructing the normal components of \(\mathbf{B}\) continuously across interfaces and evolving only those degrees of freedom; the reconstructed \(\mathbf{B}\) then satisfies \(\nabla\cdot\mathbf{B}_h=0\) exactly inside every cell.

**PosDiv-CDG positivity limiter (divergence-compatible)**  
At every quadrature node (Gauss, vertices, CAD nodes) the point value \(\mathbf{U}^*\) is limited as follows:  
1. Scale density: \(\rho'=\theta\rho+(1-\theta)\rho_{\min}\) with \(\theta\in[0,1]\) chosen so \(\rho'\ge\varepsilon>0\).  
2. Scale internal energy analogously so \(\mathcal{E}(\mathbf{U}')\ge\varepsilon\).  
3. Convert the limited state to primitives, *replace the magnetic field by the original globally DF reconstruction*, and convert back to conservatives.  

Because the magnetic field is never altered by the limiter, the global DF property is left intact while the limited point values lie in \(\mathcal{G}\).

**Modified dissipation via convex cell-average decomposition (CAD)**  
The dissipation integral is rewritten as a convex combination of point values at specially chosen CAD nodes. Those point values are replaced by their limited counterparts before the integral is evaluated. The resulting numerical flux still satisfies the GQL flux inequalities, guaranteeing that the updated cell average remains inside \(\mathcal{G}\).

**Auxiliary magnetic evolution**  
An auxiliary cell-average magnetic field \(\mathbf{Q}^*\) is advanced by a pure convex combination  
\[
\mathbf{Q}^{*,n+1}=(1-\theta\mathbf{d})\mathbf{Q}^{*,n}+\theta\mathbf{d}\mathbf{Q}_D^{*,n},
\]  
where \(\mathbf{d}\) is the CAD weight. This auxiliary field is used only inside the positivity proof; the actual evolved \(\mathbf{B}\) remains the globally DF reconstruction.

**Convex-oscillation-suppressing (COS) procedure**  
A compact, entropy-based limiter that acts *only* on the non-magnetic variables. It uses neighbouring cell averages and the entropy function \(s=\rho\ln(p\rho^{-\gamma})\) (or any convex entropy) to damp oscillations near shocks without touching \(\mathbf{B}\). Consequently both global DF and high-order accuracy are preserved.

**Main positivity theorem (cell averages)**  
Under the explicit CFL restriction  
\[
\Delta t\Bigl(\frac{\hat\alpha^x}{\Delta x}+\frac{\hat\alpha^y}{\Delta y}\Bigr)\le\frac{\theta\bar\omega_*}{2},
\quad\theta=\frac{\Delta t}{\tau_{\max}}\in(0,1],
\]  
(where \(\hat\alpha^{x,y}\) are maximum wave speeds evaluated on the limited states) the updated cell averages satisfy \(\overline{\mathbf{U}}^{n+1}\in\mathcal{G}\) whenever \(\overline{\mathbf{U}}^n\in\mathcal{G}\). The proof proceeds by showing that every supporting hyperplane of the GQL representation remains non-negative after the modified flux update, using the global DF constraint to cancel the dangerous magnetic-pressure cross terms.

**Extreme validation**  
The scheme remains positive and globally DF on low-plasma-\(\beta\) MHD jets with Mach numbers up to \(10^6\), precisely the regime where conventional high-order methods produce negative densities or pressures within a few time steps.

import numpy as np
from numpy.linalg import norm

# --- Admissible-set membership (GQL form) ---
def is_admissible(U, eps=1e-14):
    rho, mx, my, mz, Bx, By, Bz, E = U
    m2 = mx**2 + my**2 + mz**2
    B2 = Bx**2 + By**2 + Bz**2
    e_int = E - 0.5*(m2/rho + B2)
    return (rho > eps) and (e_int > eps)

# --- Divergence-compatible positivity limiter ---
def posdiv_limiter(U, B_df, rho_min=1e-12, e_min=1e-12):
    """U = (rho, m, B, E); B_df is the globally DF magnetic field."""
    rho, m, B, E = U[0], U[1:4], U[4:7], U[7]
    # 1. Density scaling
    if rho < rho_min:
        theta = (rho_min - rho_min*0.5) / (rho - rho_min*0.5 + 1e-30)
        rho = theta*rho + (1-theta)*rho_min
        m = theta*m
        E = theta*E + (1-theta)*(0.5*norm(B_df)**2 + e_min)
    # 2. Internal-energy scaling (after inserting DF magnetic field)
    kinetic = 0.5*norm(m)**2 / rho
    mag = 0.5*norm(B_df)**2
    e_int = E - kinetic - mag
    if e_int < e_min:
        theta = (e_min - e_min*0.5) / (e_int - e_min*0.5 + 1e-30)
        E = kinetic + mag + theta*e_int + (1-theta)*e_min
    return np.concatenate(([rho], m, B_df, [E]))

def cos_entropy_damping(R_nonmag, neighbours, gamma=5./3., beta=0.5):
    """Compact entropy-based oscillation suppressor."""

        R_avg = np.mean(neighbours, axis=0)
        return 0.5*(R_nonmag + R_avg)
    return R_nonmag
