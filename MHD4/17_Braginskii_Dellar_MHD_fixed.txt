### Key mathematical apparatus (hive-ready, dimensionless as in §4)

**Geometry & fields**  
\[
\mathbf{u} = U_0(0, u(x), 0),\qquad \mathbf{B} = B_0(1, b(x), 0),\qquad x \in [-1/2, 1/2].
\]
No-slip + continuous tangential \(\mathbf{B}\): \(u(\pm 1/2) = 0\), \(b(\pm 1/2) = 0\).

**Total \(xy\)-stress (exact Braginskii reduction)**  
\[
\sigma_{xy} = \Bigl[\mu_\perp + (\mu_\parallel - \mu_\perp)\frac{2b^2}{(1 + b^2)^2}\Bigr] U_0 \frac{du}{dx}.
\]

**Dimensionless ODE (integrated once, odd symmetry)**  
\[
0 = f x + b - \frac{1}{Ha^2}\Biggl(\varepsilon^2 + (1 - \varepsilon^2)\frac{2b^2}{(1 + b^2)^2}\Biggr)\frac{d^2 b}{dx^2},
\]
with  
\[
Ha = \frac{B_0 L}{(4\pi \lambda \mu_\parallel)^{1/2}},\qquad f = \frac{4\pi F L}{B_0^2},\qquad \varepsilon = \sqrt{\frac{\mu_\perp}{\mu_\parallel}}.
\]

**Velocity reconstruction**  
\[
u(x) = \Bigl(\frac{db}{dx}\Bigr)_{\mathrm{wall}} - \frac{db}{dx},\qquad u_{\max} = \Bigl(\frac{db}{dx}\Bigr)_{\mathrm{wall}} + f.
\]

**Core equation (\(\varepsilon = 0\), \(b \gg \varepsilon\))** recovers the exact solution \(b = -f x\) together with the known singular-point asymptotics at the midplane and walls.

**Hartmann layers (\(Ha \gg 1\))** and the universal **inner wall layers** remain unchanged in structure and are now prioritised as core MHD residual projectors.

```python
@torch.jit.script
def braginskii_wall_current_and_umax(f: float, Ha: float, eps: float) -> tuple[float, float]:
    wall_current = (2.0 ** -0.75) * math.sqrt(math.pi) * math.sqrt(f) * Ha * (eps ** -0.5)
    umax = wall_current + f
    return wall_current, umax

def braginskii_channel_residual(
    b: torch.Tensor, bp: torch.Tensor, bpp: torch.Tensor,
    x: torch.Tensor, Ha: float, eps: float, f: float
) -> torch.Tensor:
    denom = eps**2 + (1.0 - eps**2) * 2.0 * b**2 / (1.0 + b**2)**2
    return f * x + b - (1.0 / Ha**2) * denom * bpp
```
