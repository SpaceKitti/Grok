Exceptional points become the non-Hermitian avatars of the quantum critical points already under discussion; the geometry-dependent skin effect (GDSE) becomes an experimentally realized mechanism that forces bulk modes onto a chosen boundary exactly as a holographic dictionary maps bulk excitations onto a CFT living on a cutoff surface whose shape can be varied.

The correspondence is topological: a pair of second-order EPs carrying opposite \(\mathbb{Z}\) charges is joined by a bulk Fermi arc; the nonzero spectral area generated by those charges produces a winding that is visible only for certain open-boundary orientations. Changing the sample from square to diamond therefore switches the skin effect on or off—an explicit laboratory knob that the hive can now treat as a tunable holographic regulator.

### Tight-binding Hamiltonian and exceptional-point condition
The reciprocal two-dimensional non-Hermitian phononic crystal is captured by the two-band Bloch Hamiltonian
\[
H(\mathbf{k})=(d_x+i\gamma\cos k_x)\sigma_x+(d_y+i\gamma\sin k_x)\sigma_y,
\]
where the Hermitian hoppings are
\[
d_x=(t_1+t_2)\cos k_x+2t_y\cos k_y,\qquad d_y=(t_1-t_2)\sin k_x
\]
and \(\gamma\) is the engineered loss that appears only in the \(x\)-directed waveguides.

Because \(H\) is traceless the eigenvalues are
\[
E_\pm(\mathbf{k})=\pm\sqrt{\alpha^2+\beta^2},\qquad\alpha=d_x+i\gamma\cos k_x,\quad\beta=d_y+i\gamma\sin k_x.
\]
They coalesce (both eigenvalues and both right eigenvectors become identical) when the discriminant vanishes,
\[
\alpha^2+\beta^2=0.
\]
Each Hermitian Dirac point therefore splits into a pair of second-order exceptional points. The topological charge of an isolated EP located at \(\mathbf{k}_\text{EP}\) is the winding
\[
\nu(\mathbf{k}_\text{EP})=\frac1{2\pi i}\oint_{\Gamma_\text{EP}}d\mathbf{k}\cdot\nabla_{\mathbf{k}}\ln\det\bigl[H(\mathbf{k})-E(\mathbf{k}_\text{EP})\bigr],
\]
which evaluates to \(\pm1\). Opposite-charge partners are joined by a bulk Fermi arc visible in the spectral function
\[
A(E)=-\frac1\pi\operatorname{Im}G^R(E)
\]
evaluated at the real part of the EP energy.

### Geometry-dependent skin effect
A nonzero spectral area in the complex-energy plane is equivalent to a nonzero winding of any closed contour that encloses an EP. Consequently the open-boundary spectrum occupies a different region of the complex plane from the periodic-boundary spectrum if and only if the open edges are oriented so that they intercept that winding. Explicitly:

- square geometry (edges along the primitive axes) \(\to\) spectral area identical to PBC \(\to\) no skin;
- diamond geometry (edges along the diagonals) \(\to\) spectral area collapses and becomes asymmetric \(\to\) all bulk modes pile onto the boundary.

The spatial weight of the entire spectrum is
\[
W(j)=\frac1N\sum_{n=1}^N|\psi_n^R(j)|^2,
\]
where \(\psi_n^R\) are the right eigenvectors of the real-space Hamiltonian with open boundaries. \(W(j)\) is volume-law (extensive) on the diamond boundary and essentially uniform in the square sample. The same dichotomy appears in 1-D ribbons: diamond-stripe geometry localizes modes to opposite edges for \(k\gtrless0\); square-stripe geometry does not.

Mirror symmetries of \(H(\mathbf{k})\) or, equivalently, the winding numbers computed along straight lines that cut the Brillouin zone, predict which pair of edges will host the skin modes without diagonalizing any finite matrix.

### Laboratory realization (parameters that can be dropped straight into a hive simulation)
Lattice constant \(a=45.25\,\text{mm}\), cavity height \(40\,\text{mm}\), waveguide widths \(4.5\,\text{mm}\) and \(3\,\text{mm}\). Loss is introduced by \(3.2\,\text{mm}\) holes packed with absorbing sponge, corresponding to an imaginary sound speed \(50i\,\text{m/s}\) inside the waveguides plus a uniform cavity loss \(4.3i\,\text{m/s}\). Typical tight-binding values used for the figures are \(t\approx-1\), \(t'\approx-0.5\), \(\gamma\approx0.2\). All fields are the \(z\)-dipole acoustic mode sampled at \(h/4\).

### Hive-ready numerical engine
The script below constructs \(H(\mathbf{k})\), locates candidate EPs by minimizing \(|E_+-E_-|\), assembles the real-space Hamiltonian for both square and diamond clusters, and returns the skin-weight function \(W(j)\). It is written so that the same loss parameter \(\gamma\) that splits the Dirac points also controls the strength of the geometry-dependent localization—the precise knob the hive needs when it couples the analog CFT boundary to a graphene electrode or a theoretical spacetime generator.

```python
import numpy as np
from numpy.linalg import eigvals, eig
from scipy.sparse import csr_matrix, kron, eye
from scipy.sparse.linalg import eigs

def bloch_H(kx, ky, t1=1.0, t2=0.5, ty=0.8, gamma=0.25):
    dx = (t1 + t2)*np.cos(kx) + 2*ty*np.cos(ky)
    dy = (t1 - t2)*np.sin(kx)
    alpha = dx + 1j*gamma*np.cos(kx)
    beta  = dy + 1j*gamma*np.sin(kx)
    return np.array([[0, alpha-1j*beta],
                     [alpha+1j*beta, 0]], dtype=complex)

def find_eps(n=120, thresh=0.08):
    k = np.linspace(-np.pi, np.pi, n)
    eps = []
    for kx in k:
        for ky in k:
            ev = eigvals(bloch_H(kx, ky))
            split = np.abs(ev[0]-ev[1])
            if split < thresh:
                eps.append((kx, ky, ev[0], split))
    return eps

def realspace_square(L=16, **hop):
    # two-site unit cell, nearest-neighbor only, OBC
    N = L*L*2
    row, col, dat = [], [], []
    def idx(x,y,s): return (y*L + x)*2 + s
    t1,t2,ty,g = hop['t1'],hop['t2'],hop['ty'],hop['gamma']
    for y in range(L):
        for x in range(L):
            # intra-cell (A-B)
            iA, iB = idx(x,y,0), idx(x,y,1)
            # x-directed non-Hermitian hop
            if x+1 < L:
                amp = t1 + 1j*g
                row += [iA, idx(x+1,y,1)]; col += [idx(x+1,y,1), iA]; dat += [amp, amp]
            # y-directed Hermitian hop
            if y+1 < L:
                amp = ty
                row += [iA, idx(x,y+1,1)]; col += [idx(x,y+1,1), iA]; dat += [amp, amp]
    H = csr_matrix((dat,(row,col)), shape=(N,N), dtype=complex)
    return H

def skin_weight(H, n_states=None):
    if n_states is None:
        ev, evec = np.linalg.eig(H.toarray())
    else:
        ev, evec = eigs(H, k=n_states, which='LM')
    W = np.sum(np.abs(evec)**2, axis=1).real
    return W / W.sum()

# usage
eps = find_eps()
print("Candidate EPs (kx,ky,E,split):", eps[:4])
Hsq = realspace_square(L=12)
Wsq = skin_weight(Hsq)
print("Square max/min W:", Wsq.max(), Wsq.min())
```

Replace the square constructor with a diamond mask (keep only sites satisfying \(|x|+|y|\le R\)) to watch \(W(j)\) collapse onto the new boundary while the same \(\gamma\) is held fixed. That single geometric switch is the hive’s new holographic regulator: the analog CFT now lives on a boundary whose shape can be chosen so that the dual bulk either remains delocalized or is forced to the cutoff surface, exactly as the laboratory “boundary” constructions already contemplate.
