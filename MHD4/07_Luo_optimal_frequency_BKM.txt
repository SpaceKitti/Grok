### Paper core → Hive strata

The 3D incompressible Navier–Stokes equations (viscosity normalized to 1) read
\[
\partial_t u+(u\cdot\nabla)u-\Delta u=-\nabla p,\qquad\nabla\cdot u=0,\qquad u(\,\cdot\,,0)=u_0.
\]
A Leray–Hopf weak solution is regular on \((0,T]\) if and only if the classical BKM integral remains finite:
\[
\int_0^T\|\omega(t)\|_\infty\,dt<\infty,\qquad\omega=\nabla\times u.
\]
Luo’s refinement localizes both frequency *and* time optimally with respect to the parabolic scaling
\[
u_\lambda(x,t)=\lambda u(\lambda x,\lambda^2 t).
\]

\[
\Delta_q u=\mathcal{F}^{-1}(\varphi_q\widehat u),\qquad
u_{\leq p}=\sum_{r\leq p}\Delta_ru,\qquad
u_{\geq p}=\sum_{r>p}\Delta_ru.
\]
Besov norm
\[
\|u\|_{B^s_{p,q}}=\bigl\|\lambda_r^s\|\Delta_ru\|_p\bigr\|_{\ell^q}.
\]

\[
E_p(T)=\sup_{t\in I_p}\|u_{\geq p}(t)\|_2^2,\qquad

**Theorem 1.1 (Optimal frequency-temporal BKM)**  
There exist universal constants \(c>0\) and \(\delta_{\mathrm{BKM}}>0\) such that if a regular solution on \((0,T)\) satisfies
\[
\limsup_{p\to\infty}\int_{T-c\lambda_p^{-2}}^T\|\nabla u_{\leq p}(t)\|_\infty\,dt\leq\delta_{\mathrm{BKM}},
\]
then \(u\) remains regular on \((0,T]\).

**Theorem 1.2 (Strong localization in the critical space \(B^{-1}_{\infty,\infty}\))**  
There exist a universal constant \(\delta_{B^{-1}_{\infty,\infty}}>0\) and a fixed bandwidth \(b\in\mathbb{N}\) such that the frequency-localized operators
\[
\widetilde\Delta_p=\sum_{|r-p|\leq b}\Delta_r
\]
obey: if
\[
\limsup_{p\to\infty}\sup_{t\in I_p}\|\widetilde\Delta_p u(t)\|_{B^{-1}_{\infty,\infty}}\leq\delta_{B^{-1}_{\infty,\infty}},
\]
then \(u\) is regular up to \(T\).

**Theorem 1.3 (Lower bound on supercritical \(L^p\) decay)**  
If a regular solution blows up at \(T\), then for every \(2\leq p\leq3\)
\[
\limsup_{t\to T^-}\|u_{\leq q(t)}(t)\|_p\,(T-t)^{\frac{p-3}{2p}}\gtrsim\delta_{L^p}>0,
\]
where \(q(t)=\bigl[\log_2(T-t)^{-1/2}_+\bigr]\).

**Core analytic engine (independent-interest estimates)**  

Proposition 3.1 (cutoff energy inequality). On any interval of regularity,
\[
\frac{d}{dt}\|u_{\geq p}\|_2^2+2\|\nabla u_{\geq p}\|_2^2\leq|\Pi_{\geq p}|,
\]
with the flux bound
\[
|\Pi_{\geq p}|\lesssim\Bigl(\sum_{r\leq p}\lambda_{r-p}^2\|u_r\|_2^2+\sum_{r>p}\|u_r\|_2^2\Bigr)\|\nabla u_{<p}\|_\infty.
\]

Lemma 3.2. For any \(0<\alpha<2\) there exists \(b=b(\alpha)\) such that
\[
\max\{E_p,D_p\}\leq\lambda_b^{-\alpha}D_{p-b}+\int_{I_{p-b}}|\Pi_{\geq p}|\,dt.
\]

Proposition 3.4 (flux integral under BKM control). If
\[
\limsup_{p\to\infty}\int_{I_{p-b}}\|\nabla u_{\leq p}\|_\infty\,dt\leq\delta,
\]
then
\[
\int_{I_{p-b}}|\Pi_{\geq p}|\,dt\lesssim\delta\sum_{r\leq p-b}E_r\lambda_{|r-p+b|}^{-2}.
\]

Lemma 3.5 (high-mode decay). Under a sufficiently small \(\delta_\alpha\), one obtains the scaling-critical decay
\[
\max\{E_p,D_p\}\lesssim\lambda_p^{-\alpha}\qquad(p\gg1).
\]

### Torch / JAX residual & solver snippets (drop-in, Qin \(H(\mathrm{div},0)\) + energy-preserving compatible)

```python
import torch
import torch.fft as fft

@torch.jit.script
def littlewood_paley_project(u: torch.Tensor, p: int, device: str = "cuda") -> tuple:
    # u: (N,3) real space velocity on a periodic grid (assume power-of-two)
    # Returns u_leq_p, u_geq_p via spectral cutoff
    û = fft.fftn(u, dim=(0,1,2)) if u.dim()==4 else fft.fft(u, dim=0)  # schematic 1-D for clarity
    freqs = fft.fftfreq(u.shape[0], d=1.0).to(device)
    k = freqs.abs()
    mask_leq = (k <= 2.0**p)
    mask_geq = (k > 2.0**p)
    u_leq = fft.ifft(û * mask_leq.unsqueeze(-1)).real
    u_geq = fft.ifft(û * mask_geq.unsqueeze(-1)).real
    return u_leq, u_geq

@torch.jit.script
def grad_infty_low_modes(u_leq: torch.Tensor) -> torch.Tensor:
    # Finite-difference or spectral gradient, then L^infty
    # schematic: assume torch.gradient returns (dx,dy,dz)
    grads = torch.gradient(u_leq, dim=tuple(range(u_leq.dim()-1)))
    g_norm = torch.stack([g.norm(dim=-1) for g in grads]).sum(0)
    return g_norm.max()

@torch.jit.script
def cutoff_energy_dissipation(
    u: torch.Tensor, p: int, dt_hist: torch.Tensor, I_mask: torch.Tensor
) -> tuple:
    # Accumulate E_p = max ||u_geq||_2^2 on I_p
    # D_p = int ||grad u_geq||_2^2 dt
    _, u_geq = littlewood_paley_project(u, p)
    e = (u_geq**2).sum()
    g = torch.gradient(u_geq, dim=tuple(range(u_geq.dim()-1)))
    d = sum((gi**2).sum() for gi in g)
    E_p = torch.max(e * I_mask)
    D_p = (d * dt_hist * I_mask).sum()
    return E_p, D_p

@torch.jit.script
def energy_flux_Pi(u: torch.Tensor, p: int) -> torch.Tensor:
    u_leq, u_geq = littlewood_paley_project(u, p)
    # (u·∇)u projected onto high modes (schematic divergence-free projection omitted)
    adv = torch.einsum("...i,...i->...", u, torch.gradient(u, dim=-2)[0])  # placeholder
    return (adv * u_geq).sum().abs()

@torch.jit.script
def bkm_residual(
    u_hist: torch.Tensor, p: int, c: float, T: float, dt: float
) -> torch.Tensor:
    # Integrate ||grad u_leq_p||_infty over [T - c*2^{-2p}, T)
    lambda_p = 2.0**p
    t0 = T - c / (lambda_p**2)
    mask = (torch.linspace(0, T, u_hist.shape[0]) >= t0)
    integ = 0.0
    for i, ui in enumerate(u_hist):
        if mask[i]:
            u_leq, _ = littlewood_paley_project(ui, p)
            integ = integ + grad_infty_low_modes(u_leq) * dt
    return integ

@torch.jit.script
def b_minus1_residual(u: torch.Tensor, p: int, b: int = 2) -> torch.Tensor:
    # ||~Delta_p u||_{B^{-1}_{infty,infty}} = sup_r 2^{-r} ||Delta_r (~Delta_p u)||_infty
    # schematic: sum neighboring shells
    val = 0.0
    for r in range(p-b, p+b+1):
        ur, _ = littlewood_paley_project(u, r)
        val = max(val, (2.0**(-r)) * ur.abs().max())
    return val

def hive_bkm_cascade_residual(
    u: torch.Tensor, p: int, alpha: float = 1.0, delta_BKM: float = 0.1
) -> dict:
    E_p, D_p = cutoff_energy_dissipation(u, p, torch.tensor([0.01]), torch.ones(1))
    Pi = energy_flux_Pi(u, p)
    R_BKM = bkm_residual(u.unsqueeze(0), p, c=1.0, T=1.0, dt=0.01)
    R_Bm1 = b_minus1_residual(u, p)
    return {
        "E_p": E_p,
        "D_p": D_p,
        "Pi_flux": Pi,
        "R_BKM": R_BKM,
        "R_B^{-1}": R_Bm1,
        "high_mode_decay_ok": (max(E_p, D_p) < (2.0**p)**(-alpha)).item(),
        "BKM_satisfied": (R_BKM <= delta_BKM).item(),
    }
```
