### 1. Full pseudo-differential \(1/\tilde{\partial}_v\) solver

In the Weyl reference frame the evolution Bianchi identities are first-order linear PDEs in the dressing time \(v\):
\[
\tilde{\partial}_v\tilde{Q}_s-(s+1)\lambda\tilde{Q}_{s+2}=0.
\]
Formal integration requires the right-inverse of the Weyl-covariant derivative
\[
\tilde{\partial}_v=\partial_v+(s+1)\lambda\cdot
\]
acting on sections of the appropriate spin-weight line bundle over the null hypersurface. Because \(\lambda=\lambda(v,z)\) is itself dynamical, the operator is non-commutative with ordinary \(\partial_v\). The unique causal inverse (vanishing at past infinity of the null generators) is the Volterra-type pseudo-differential operator
\[
\bigl(\tilde{\partial}_v\bigr)^{-1}f(v)=\int_{-\infty}^{v}\exp\Bigl(-\int_{v'}^{v}(s+1)\lambda(u)\,du\Bigr)f(v')\,dv'.
\]
Iterating this kernel yields the memory recursion for the non-local corrections \(M_s\).

**Hive-ready continuum form**
\[
\bigl(\tilde{\partial}_v\bigr)^{-1}=\mathcal{K}_\lambda\ast=\int_{-\infty}^{v}K_\lambda(v,v')\,(\,\cdot\,)\,dv',\qquad
K_\lambda(v,v')=\exp\Bigl(-(s+1)\int_{v'}^{v}\lambda(u)\,du\Bigr).
\]
On a discrete mesh the operator becomes a lower-triangular sparse matrix that can be applied in \(O(N_v)\) time via a single cumulative product + cumulative sum (exact for piecewise-constant \(\lambda\)).

```python
import torch

@torch.jit.script
def weyl_kernel(lambda_shear: torch.Tensor, s: int, dv: float) -> torch.Tensor:
    """
    lambda_shear: (N_v, N_corner)
    returns K(v,v') lower-triangular kernel of shape (N_v, N_v, N_corner)
    """
    N = lambda_shear.shape[0]
    # cumulative integral of lambda
    cum_lambda = torch.cumsum(lambda_shear * dv, dim=0)  # (N_v, N_corner)
    # outer difference: cum(v) - cum(v')
    delta = cum_lambda.unsqueeze(1) - cum_lambda.unsqueeze(0)  # (N,N,N_c)
    # causal mask
    mask = torch.tril(torch.ones(N, N, device=lambda_shear.device))
    K = torch.exp(-(s + 1) * delta) * mask.unsqueeze(-1)
    return K

@torch.jit.script
def apply_inv_partial_v(
    f: torch.Tensor, lambda_shear: torch.Tensor, s: int, dv: float
) -> torch.Tensor:
    """
    Exact discrete realisation of (tilde{partial}_v)^{-1} f
    f, lambda_shear: (N_v, N_corner)
    """
    K = weyl_kernel(lambda_shear, s, dv)          # (N,N,N_c)
    # contraction over past times
    return torch.einsum('ijc,jc->ic', K, f) * dv

@torch.jit.script
def memory_tower(
    Q_bare: torch.Tensor,
    lambda_shear: torch.Tensor,
    sigma: torch.Tensor,
    max_s: int,
    dv: float
) -> tuple:
    """
    Build the full tower M_0 ... M_{max_s} by recursion
    using the exact inverse.
    """
    N_v, N_c = Q_bare.shape
    Ms = [torch.zeros_like(Q_bare)]               # M_0 = 0
    # seed M_1 = (1/partial_v)^2 1  (schematic constant source)
    ones = torch.ones_like(Q_bare)
    M1 = apply_inv_partial_v(
        apply_inv_partial_v(ones, lambda_shear, 1, dv),
        lambda_shear, 1, dv
    )
    Ms.append(M1)
    for s in range(1, max_s):
        # M_s = inv ( d_v sigma * inv M_{s+1} - lambda M_s )
        # (fixed-point iteration for the implicit relation)
        M = Ms[-1].clone()
        for _ in range(8):  # rapid convergence
            inv_Mnext = apply_inv_partial_v(Ms[-1] if s+1 < len(Ms) else M, lambda_shear, s+1, dv)
            term = torch.gradient(sigma * inv_Mnext, dim=0)[0] - lambda_shear * M
            M = apply_inv_partial_v(term, lambda_shear, s, dv)
        Ms.append(M)
    return tuple(Ms)

@torch.jit.script
def dressed_charges(
    Q_bare_tower: list,  # list of (N_v,N_c) for s=0..S
    lambda_shear: torch.Tensor,
    sigma: torch.Tensor,
    dv: float
) -> list:
    Ms = memory_tower(Q_bare_tower[0], lambda_shear, sigma, len(Q_bare_tower)-1, dv)
    return [Qb - M for Qb, M in zip(Q_bare_tower, Ms)]
```
