### 1. Bateman construction of null fields (exact paper §II)
A pair of complex scalars \((\alpha,\beta)\) obeying the first-order condition
\[
\nabla\alpha\times\nabla\beta=i\bigl(\partial_t\alpha\,\nabla\beta-\partial_t\beta\,\nabla\alpha\bigr)
\]
generates the Riemann–Silberstein vector
\[
\mathbf{F}=\mathbf{E}+i\mathbf{B}=\nabla\alpha\times\nabla\beta.
\]
Nullity is automatic:
\[
\mathbf{E}\cdot\mathbf{B}=0,\qquad|\mathbf{E}|^2-|\mathbf{B}|^2=0.
\]
The non-triviality constraints
\[
\partial_t\alpha\bigl((\partial_t\alpha)^2-|\nabla\alpha|^2\bigr)=0,\qquad
\partial_t\beta\bigl((\partial_t\beta)^2-|\nabla\beta|^2\bigr)=0
\]
guarantee a genuine null congruence. Holomorphic reparametrizations
\[
\mathbf{F}=h(\alpha,\beta)\,\nabla\alpha\times\nabla\beta=\nabla f(\alpha,\beta)\times\nabla g(\alpha,\beta)
\]
with
\[
h=\partial_\alpha f\,\partial_\beta g-\partial_\beta f\,\partial_\alpha g
\]
leave the field lines invariant while rescaling the intensity. This is the precise continuous analogue of the hive’s discrete Wilson-loop / plaquette reweighting and of the frozen-in magnetic flux condition of ideal MHD.

from scipy.integrate import solve_ivp
from numpy.linalg import norm

def alpha_beta(x, y, z, t):
    r2 = x**2 + y**2 + z**2
    denom = r2 - (t - 1j)**2
    a = (r2 - t**2 - 1 + 2j*z) / denom
    b = 2*(x - 1j*y) / denom
    return a, b

def F_field(x, y, z, t, p=2, q=3, eps=1e-8):
    """Riemann-Silberstein vector via finite differences on alpha^p, beta^q."""
    a, b = alpha_beta(x, y, z, t)
    ap = a**p
    bq = b**q
    # central differences for gradients

    apx, bqx = alpha_beta(x+dx,y,z,t)

    d_bq = np.array([(bqx**q - bq)/dx, (bqy**q - bq)/dx, (bqz**q - bq)/dx])
