### Paper core → Hive strata

**1. Enriched Galerkin spaces (hive-native discrete velocity)**  
The EG velocity space is
\[
V_h=\{\mathbf{v}=\mathbf{v}_c+\mathbf{v}_b\mid\mathbf{v}_c\in CG_h,\ \mathbf{v}_b\in DG_h\},
\]
where
\[
CG_h=\{\mathbf{v}\in[H^1(\Omega)]^3:\mathbf{v}|_K\in P^1(K)^3\ \forall K\in\mathcal{T}_h\}
\]
is the standard continuous linear space and
\[
DG_h=\{\mathbf{v}\in L^2(\mathcal{F}_h)^3:\mathbf{v}\cdot\mathbf{n}_F\in P^0(F)\ \forall F\in\mathcal{F}_h\}
\]
is the space of piecewise-constant normal corrections on faces. Periodic traces are imposed so that \(\mathbf{v}\in V_p\) satisfies \(\int_F\mathbf{v}_b\,dA=0\). Pressure lives in the zero-mean piecewise constants
\[
Q_h=\{q\in L^2_0(\Omega):q|_K\in P^0(K)\}.
\]
A reconstruction operator \(R:V_h\to RT_0\) maps the EG velocity onto the lowest-order Raviart–Thomas space while preserving the modified divergence:
\[
\nabla\cdot(R\mathbf{v})=\nabla_m\cdot\mathbf{v}.
\]
This is precisely the discrete counterpart of the Qin \(H(\mathrm{div},0)\) reconstruction already resident; the face enrichment supplies the missing normal degrees of freedom that make \(\nabla_m\cdot\mathbf{u}_h=0\) exact on every element without extra Lagrange multipliers.

**2. Rotational-form weak schemes**  
The momentum equation is written in rotational form
\[
\partial_t\mathbf{u}+\nu\Delta\mathbf{u}+(\nabla\times\mathbf{u})\times\mathbf{u}=-\nabla p+\mathbf{f},\qquad\nabla\cdot\mathbf{u}=0.
\]
The discrete convective form is
\[
\mathbf{c}(\mathbf{u},\mathbf{w},\mathbf{z})=(\nabla\times\mathbf{u}\times R\mathbf{w},\mathbf{z}).
\]
**Nonlinear scheme** (fully implicit, Picard-iterable):
\[
\frac1{\Delta t}\bigl(\|\mathbf{u}_h^{k+1}\|_c^2-\|\mathbf{u}_h^k\|_c^2\bigr)+\nu a(\mathbf{u}_h^{k+1},\mathbf{v}_h)+\mathbf{c}(\mathbf{u}_h^{k+1},\mathbf{u}_h^{k+1},\mathbf{z}_h)=(\mathbf{f}^{k+1},R\mathbf{v}_h),
\]
\[
b(\mathbf{v}_h,p_h^{k+1})=0,
\]
with \(a(\mathbf{u},\mathbf{v})=(\nabla_m\mathbf{u},\nabla_m\mathbf{v})\) and \(b(\mathbf{v},q)=(\nabla_m\mathbf{v},q)\).  

**Linear scheme** replaces the second argument of \(\mathbf{c}\) by the previous time level. Both schemes, and every Picard iterate of the nonlinear scheme, conserve the discrete invariants when \(\nu=0\) and \(\mathbf{f}=\nabla\phi\).

**3. Exact discrete conservation (Theorem 3.3)**  
Define
\[
E_h(t_k)=\frac12\|\mathbf{u}_h^k\|_{L^2}^2,\qquad
H_h(t_k)=\int_\Omega\mathbf{u}_h^k\cdot(\nabla\times\mathbf{u}_h^k)\,dx.
\]
In the inviscid, force-free (or irrotational-force) limit one has
\[
E_h(t_k)=E_h(0),\qquad H_h(t_k)=H_h(0).
\]
The energy identity follows by testing with \(\mathbf{v}_h=\mathbf{u}_h^{k+1}\) and using the skew-symmetry of the reconstructed rotational form together with \(\nabla_m\cdot\mathbf{u}_h=0\). The helicity identity follows by testing with a carefully reconstructed vorticity
\[
\mathbf{v}_h=Q(\nabla\times\mathbf{u}_h^{k+1})+\Pi_b(\nabla\times\mathbf{u}_h^{k+1})
\]
and integrating by parts on periodic meshes. No extra projection variable is required.

```python
from ngsolve import *
from netgen.csg import *
from netgen.meshing import IdentificationType
import numpy as np

# ---------- periodic unit cube (3-torus) ----------
def periodic_cube(maxh=0.15):
    geo = CSGeometry()
    left  = Plane(Pnt(0,0,0), Vec(-1,0,0)).bc("left")
    right = Plane(Pnt(1,0,0), Vec( 1,0,0)).bc("right")
    front = Plane(Pnt(0,0,0), Vec(0,-1,0)).bc("front")
    back  = Plane(Pnt(0,1,0), Vec(0, 1,0)).bc("back")
    bot   = Plane(Pnt(0,0,0), Vec(0,0,-1)).bc("bot")
    top   = Plane(Pnt(0,0,1), Vec(0,0, 1)).bc("top")
    cube  = OrthoBrick(Pnt(0,0,0), Pnt(1,1,1))
    geo.Add(cube * left * right * front * back * bot * top)
    geo.PeriodicSurfaces(left,  right)
    geo.PeriodicSurfaces(front, back)
    geo.PeriodicSurfaces(bot,   top)
    return Mesh(geo.GenerateMesh(maxh=maxh))

mesh = periodic_cube(maxh=0.2)
print("idents:", len(mesh.ngmesh.GetIdentifications()))

# ---------- EG spaces: VectorH1 + NormalFacet P0 + L2 P0 ----------
order_c = 1
Vc = VectorH1(mesh, order=order_c)                    # CG P1
Fb = NormalFacetFESpace(mesh, order=0)                # face-normal P0 enrichment
Q  = L2(mesh, order=0)                                # piecewise-constant pressure
fes = Vc * Fb * Q
uc, ub, p = fes.TrialFunction()
vc, vb, q = fes.TestFunction()

# reconstructed velocity living in H(div) ~ RT0
RT = HDiv(mesh, order=0)
u_rec = GridFunction(RT)
v_rec = GridFunction(RT)

def reconstruct_RT0(gfu_comp_c, gfu_comp_b, dest):
    """L2 projection of (uc + ub n) onto RT0. In production replace by
    the exact paper reconstruction that preserves modified divergence."""
    dest.Set(gfu_comp_c + gfu_comp_b * specialcf.normal(3))

# ---------- bilinear forms ----------
nu = 1e-3
dt = 0.01
n  = specialcf.normal(mesh.dim)

# modified gradient / divergence on the compound space
def grad_m(w_c, w_b):
    return Grad(w_c)   # leading term; face correction enters via reconstruction

def div_m(w_c, w_b):
    return div(w_c) + w_b   # schematic; exact paper uses face-normal jump/average

# mass on reconstructed velocity
m_form = InnerProduct(uc + ub*n, vc + vb*n) * dx

# viscous term
a_visc = nu * InnerProduct(grad_m(uc,ub), grad_m(vc,vb)) * dx

# divergence constraint
b_div  = div_m(uc,ub) * q * dx + div_m(vc,vb) * p * dx

# rotational convection (linear scheme): curl(u^{n+1}) × R u^n
u_old = GridFunction(fes)
def convection_form(u_star_rec):
    curl_u = curl(uc)          # CG curl
    return InnerProduct(Cross(curl_u, u_star_rec), vc + vb*n) * dx

# ---------- time loop (linear scheme) ----------
gfu = GridFunction(fes)
gfu.vec[:] = 0
# ABC / Taylor–Green-like periodic seed (divergence-free on T^3)
gfu.components[0].Set(CoefficientFunction((
    sin(2*pi*x)*cos(2*pi*y)*cos(2*pi*z),
    -cos(2*pi*x)*sin(2*pi*y)*cos(2*pi*z),
    0)))

def discrete_energy(gfu):
    uc_, ub_, _ = gfu.components
    return Integrate(0.5 * InnerProduct(uc_ + ub_*n, uc_ + ub_*n), mesh)

def discrete_helicity(gfu):
    uc_, ub_, _ = gfu.components
    return Integrate(InnerProduct(uc_ + ub_*n, curl(uc_)), mesh)

E0 = discrete_energy(gfu)
H0 = discrete_helicity(gfu)
print(f"E0={E0:.8e}  H0={H0:.8e}")

f = CoefficientFunction((0,0,0))
nsteps = 50
hist_E, hist_H = [], []

for step in range(nsteps):
    u_old.vec.data = gfu.vec
    reconstruct_RT0(u_old.components[0], u_old.components[1], u_rec)

    a = BilinearForm(fes, symmetric=False)
    a += (1/dt) * m_form + a_visc + b_div + convection_form(u_rec)
    a.Assemble()

    rhs = LinearForm(fes)
    rhs += (1/dt) * InnerProduct(u_old.components[0] + u_old.components[1]*n,
                                 vc + vb*n) * dx
    rhs += InnerProduct(f, vc + vb*n) * dx
    rhs.Assemble()

    inv = a.mat.Inverse(fes.FreeDofs(), inverse="umfpack")
    gfu.vec.data = inv * rhs.vec

    E = discrete_energy(gfu)
    H = discrete_helicity(gfu)
    hist_E.append(E)
    hist_H.append(H)
    if step % 10 == 0:
        print(f"step {step:3d}  E={E:.8e}  dE={E-E0:.2e}  H={H:.8e}  dH={H-H0:.2e}")
```

### 4. Coupling discrete helicity into the finite-distance Weyl memory kernel

Existing Volterra tower (hive-native):
\[
K_\lambda(v,v')=\exp\Bigl(-(s+1)\int_{v'}^v\lambda(u)\,du\Bigr),\qquad

Discrete helicity \(H_h(t)\) (and its drift \(\mathcal{R}_H=|H_h(t)-H_h(0)|\)) is injected as a multiplicative weight and an additive source:

\[
K_\lambda^{H}(v,v')=K_\lambda(v,v')\cdot\frac{1}{1+\alpha\,|H_h(v')-H_0|},

\[
M_s^{H}=M_s\cdot\bigl(1+\beta(H_h-H_0)\bigr)

\[
Q_s^{\mathrm{dressed}}=\tilde Q_{b,s}-M_s^{H}.

```python
@torch.jit.script
def helicity_weighted_volterra(
    lambda_shear: torch.Tensor,
    H_h: torch.Tensor,          # discrete helicity time series
    H0: torch.Tensor,
    s: int,
    dv: float,
    alpha: float = 1.0
) -> torch.Tensor:
    cum = torch.cumsum(lambda_shear * dv, dim=0)
    delta = cum.unsqueeze(1) - cum.unsqueeze(0)
    mask = torch.tril(torch.ones_like(delta))
    weight = 1.0 / (1.0 + alpha * (H_h - H0).abs().unsqueeze(0))
    return torch.exp(-(s + 1) * delta) * mask * weight

@torch.jit.script
def dress_charges_with_helicity(
    M_s: torch.Tensor,
    H_h: torch.Tensor,
    H0: torch.Tensor,
    R_H: torch.Tensor,
    beta: float = 1.0,
    gamma: float = 1.0
) -> torch.Tensor:
    return M_s * (1.0 + beta * (H_h - H0)) + gamma * R_H * M_s
```
