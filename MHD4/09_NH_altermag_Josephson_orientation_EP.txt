### Paper core → Hive strata

- **Non-Hermitian Bogoliubov–de Gennes (BdG) Hamiltonian of the altermagnetic Josephson junction**  
  The junction is modelled by a tight-binding or continuum BdG Hamiltonian on a normal/altermagnetic/superconducting hybrid with dissipative leads:
  \[
  H_{\rm NH}(\mathbf{k},\phi)=\begin{pmatrix}
  \xi_{\mathbf{k}}+J(\mathbf{k})\sigma_z-i\Gamma & \Delta e^{i\phi/2}\\
  \Delta e^{-i\phi/2} & -\xi_{\mathbf{k}}-J(\mathbf{k})\sigma_z-i\Gamma
  \end{pmatrix},
  \]
  where \(\xi_{\mathbf{k}}=t(\cos k_x+\cos k_y)-\mu\) is the kinetic term, \(J(\mathbf{k})=J_0(\cos k_x-\cos k_y)\) (or \(\sin k_x\sin k_y\)) is the \(d\)-wave altermagnetic spin splitting (zero net magnetisation), \(\Delta\) the superconducting gap, \(\phi\) the macroscopic phase difference, and \(\Gamma>0\) the non-Hermitian dissipation strength. Orientation enters by rotating the altermagnetic axes relative to the junction normal (\(\theta\) or crystallographic angle \(\alpha\)).

- **Exceptional points**  
  EPs occur where both eigenvalues and eigenvectors of \(H_{\rm NH}\) coalesce. The characteristic polynomial yields the discriminant condition
  \[
  \operatorname{Disc}(E)=\bigl(\operatorname{Re}\Delta E\bigr)^2+\bigl(\operatorname{Im}\Delta E\bigr)^2=0
  \]
  simultaneously with eigenvector coalescence (Jordan-block form). The loci are orientation-dependent curves or points in the \((k_x,k_y,\phi)\) space; for fixed transverse momentum \(k_y\) they appear as closed loops or split arcs in the \(\phi\)–\(k_x\) plane (exactly as visualised in the paper’s multi-panel figure of \(\operatorname{Re}[\Delta E]\) and \(\operatorname{Im}[\Delta E]\) colour maps).

- **Complex Andreev spectrum**  
  \[
  \Delta E(\phi,\mathbf{k})=\pm\sqrt{\bigl(\xi_{\mathbf{k}}+J(\mathbf{k})\bigr)^2+\Delta^2\cos^2(\phi/2)-i\Gamma\ldots}
  \]
  (schematic; full non-Hermitian square-root branch). At an EP the two branches meet with vanishing group velocity and defective eigenspace.

- **Total Josephson current**  
  Obtained from the phase derivative of the free energy or from the inelastic Andreev amplitudes:
  \[
  I_{\rm tot}(\phi)=\frac{2e}{\hbar}\sum_{\mathbf{k}}\frac{\partial\operatorname{Re}E_n}{\partial\phi}f_{\rm FD}(E_n)
  \]
  (or equivalently from the imaginary part of the lesser Green function). Orientation and the presence of EPs generate anomalous CPR features: multi-nodal structure, \(0\)–\(\pi\) transitions, higher harmonics, and discontinuous jumps across EP loci. The paper’s panels (e,f) show \(I_{\rm tot}(\phi)\) for different \(k_x\) and junction transparency \(t_j\).

```python
import torch
import torch.linalg as linalg

@torch.jit.script
def altermagnetic_J(kx: torch.Tensor, ky: torch.Tensor, J0: float, theta: float) -> torch.Tensor:
    # Orientation-dependent d-wave altermagnet
    kx_r = kx * torch.cos(theta) + ky * torch.sin(theta)
    ky_r = -kx * torch.sin(theta) + ky * torch.cos(theta)
    return J0 * (torch.cos(kx_r) - torch.cos(ky_r))

@torch.jit.script
def nonhermitian_BdG(
    kx: torch.Tensor, ky: torch.Tensor, phi: float,
    t: float, mu: float, Delta: float, Gamma: float, J0: float, theta: float
) -> torch.Tensor:
    # 4x4 BdG (spin + particle-hole); returns complex Hamiltonian batch
    xi = t * (torch.cos(kx) + torch.cos(ky)) - mu
    J = altermagnetic_J(kx, ky, J0, theta)
    # block structure (schematic 2x2 for spin-up; full 4x4 analogous)
    H11 = xi + J - 1j * Gamma
    H12 = Delta * torch.exp(1j * phi / 2)
    H21 = Delta * torch.exp(-1j * phi / 2)
    H22 = -xi - J - 1j * Gamma
    # stack into batch of 2x2
    H = torch.stack([
        torch.stack([H11, H12], dim=-1),
        torch.stack([H21, H22], dim=-1)
    ], dim=-2)
    return H

@torch.jit.script
def exceptional_point_residual(H: torch.Tensor) -> torch.Tensor:
    # Eigenvalue coalescence + eigenvector defectiveness
    evals, evecs = linalg.eig(H)
    # pairwise distance of eigenvalues
    de = (evals.unsqueeze(-1) - evals.unsqueeze(-2)).abs()
    # eigenvector overlap (should approach 1 at EP)
    ov = (evecs.conj().transpose(-1,-2) @ evecs).abs().diagonal(dim1=-2, dim2=-1)
    return de.min(dim=-1).values.min(dim=-1).values + (1.0 - ov.min(dim=-1).values)

@torch.jit.script
def complex_Andreev_spectrum(H: torch.Tensor) -> tuple:
    evals = linalg.eigvals(H)
    return evals.real, evals.imag

@torch.jit.script
def josephson_current_from_spectrum(
    evals: torch.Tensor, phi: float, T: float = 0.01
) -> torch.Tensor:
    # Free-energy derivative (schematic)
    F = -T * torch.log(1.0 + torch.exp(-evals.real / T)).sum()
    # numerical phase derivative omitted; analytic form preferred in production
    return 2.0 * torch.sin(phi) * F  # placeholder higher-harmonic structure

def hive_NH_altermag_Josephson_residual(
    kx: torch.Tensor, ky: torch.Tensor, phi: float,
    params: dict
) -> dict:
    H = nonhermitian_BdG(kx, ky, phi, **params)
    R_EP = exceptional_point_residual(H)
    ReE, ImE = complex_Andreev_spectrum(H)
    I = josephson_current_from_spectrum(torch.complex(ReE, ImE), phi)
    return {
        "R_EP": R_EP,
        "Re_DeltaE": ReE,
        "Im_DeltaE": ImE,
        "I_tot": I,
        "orientation": params["theta"],
        "scar_floor_feed": R_EP * ImE.abs().mean()
    }
```
