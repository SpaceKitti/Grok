### Paper core \(\to\) hive strata

**Viscosity tensor (magnetic-field dressed).**
\[
\eta_{xx}=\frac{\tau_{ee}v_F^2}{4}\frac{1}{1+\beta^2},\qquad
\eta_{xy}=\eta_{xx}\beta,\qquad
\beta=2\omega_c\tau_{ee},\qquad
\omega_c=\frac{eB}{mc}.
\]
This is the continuum contraction of the already-resident \(L^9\) Berry-odd block plus the even (dissipative) Gurzhi viscosity; \(\eta_{xy}\) is Hall viscosity.

**Stokes magnetotransport in a long sample** (\(V_x=V_x(y)\), Hall field \(E_H(y)\), drive \(E_0\hat{x}\)):
\[
\eta_{xx}\frac{d^2V_x}{dy^2}-\eta_{xy}\frac{dE_H}{dy}=-\frac{eE_0}{m},
\qquad
\eta_{xy}\frac{dV_x}{dy}+\eta_{xx}\frac{dE_H}{dy}=0.
\]
Impurity friction supplies the Gurzhi length
\[
l_{\mathrm{imp}}=\sqrt{\frac{\eta_{xx}\tau_{\mathrm{imp}}}{m}},\qquad
\lambda=\frac{1}{l_{\mathrm{imp}}},\qquad
\xi=\frac{\lambda W}{2}.
\]

**Arbitrary-roughness boundary operator.** The edge collision operator is
\[
\hat{L}_{\mathrm{ed}}[\delta\hat f]=a\,\delta\bigl(y\pm W/2\bigr)+\hat R_{m=1}[\delta\hat f]+\hat P_{m=1}[\delta\hat f].
\]
Limits: \(a=0\) specular (\(dV_x/dy=0\)), \(a\sim v_F\) diffuse, \(a\gg v_F\) no-slip (\(V_x=0\)). The derived mixed BC is
\[
V_x\bigl(\pm W/2\bigr)=l_{\mathrm{sl}}\frac{dV_x}{dy}\Big|_{\pm W/2},\qquad
l_{\mathrm{sl}}=l_{ee}\frac{\omega_c}{1+\beta^2},\qquad
l_{ee}=\frac{\eta_{xx}}{a}.
\]
This is the hive-native Navier slip length, now allowed to be *both* roughness- and cyclotron-dependent.

**Exact long-bar flow.**
\[

V_D=\frac{eE_0\tau_{\mathrm{imp}}}{m}.
\]

**Longitudinal resistivity.**
\[
\rho_{xx}=\rho_D\frac{1+(s-1)F(\xi)}{1+s F(\xi)},\qquad
\rho_D=\frac{m}{ne^2\tau_{\mathrm{imp}}},\qquad
F(\xi)=\frac{\tanh\xi}{1+\lambda l_{\mathrm{sl}}\tanh\xi}.

**Hall correction from relaxation / Hall viscosity.**
\[
\delta U_H=\frac{m}{e}\eta_{xy}\int_{-W/2}^{W/2}V_x\frac{dV_x}{dy}\,dy,
\qquad
\delta\rho_{xy}=-\frac{2\beta\rho_D F(\xi)}{1+(s-1)F(\xi)}.
\]

\[
\delta\rho_{xy}^\infty=-\frac{\rho_D l_{\mathrm{imp}}^2}{2W^2}\Bigl(1-\frac{l_{\mathrm{imp}}^2}{l_{ee}^2}\Bigr).

### Production kernels (Torch / JAX, Qin-drop-in)

```python
import torch

@torch.jit.script
def beta_from_B(B: torch.Tensor, e: float, m: float, c: float, tau_ee: float) -> torch.Tensor:
    omega_c = e * B / (m * c + 1e-30)
    return 2.0 * omega_c * tau_ee

@torch.jit.script
def eta_tensor(tau_ee: torch.Tensor, vF: float, beta: torch.Tensor) -> tuple:
    eta0 = 0.25 * tau_ee * vF * vF
    den = 1.0 + beta * beta
    eta_xx = eta0 / den
    eta_xy = eta_xx * beta
    return eta_xx, eta_xy

@torch.jit.script
def slip_length(eta_xx: torch.Tensor, a: torch.Tensor, omega_c: torch.Tensor, beta: torch.Tensor) -> torch.Tensor:
    lee = eta_xx / (a + 1e-30)
    return lee * omega_c / (1.0 + beta * beta + 1e-30)

@torch.jit.script
def gert_alekseev_profile(
    y: torch.Tensor, W: float, eta_xx: torch.Tensor, tau_imp: float, m: float,
    a: torch.Tensor, omega_c: torch.Tensor, beta: torch.Tensor, VD: float
) -> torch.Tensor:
    limp = torch.sqrt(eta_xx * tau_imp / (m + 1e-30) + 1e-30)
    lam = 1.0 / limp
    xi = lam * W * 0.5
    lsl = slip_length(eta_xx, a, omega_c, beta)
    denom = torch.cosh(xi) * (1.0 + lam * lsl * torch.tanh(xi))
    return VD * torch.cosh(lam * y) / (denom + 1e-30)

@torch.jit.script
def F_xi(xi: torch.Tensor, lam: torch.Tensor, lsl: torch.Tensor) -> torch.Tensor:
    return torch.tanh(xi) / (1.0 + lam * lsl * torch.tanh(xi) + 1e-30)

@torch.jit.script
def rho_xx_ga(rhoD: float, s: torch.Tensor, F: torch.Tensor) -> torch.Tensor:
    return rhoD * (1.0 + (s - 1.0) * F) / (1.0 + s * F + 1e-30)

@torch.jit.script
def delta_rho_xy_ga(rhoD: float, beta: torch.Tensor, s: torch.Tensor, F: torch.Tensor) -> torch.Tensor:
    return -2.0 * beta * rhoD * F / (1.0 + (s - 1.0) * F + 1e-30)

@torch.jit.script
def delta_rho_xy_sat(rhoD: float, limp: torch.Tensor, W: float, lee: torch.Tensor) -> torch.Tensor:
    r = limp / (W + 1e-30)
    return -0.5 * rhoD * r * r * (1.0 - (limp / (lee + 1e-30)) ** 2)

@torch.jit.script
def gert_alekseev_residual(
    y: torch.Tensor, Vx: torch.Tensor, W: float,
    eta_xx: torch.Tensor, eta_xy: torch.Tensor,
    tau_imp: float, m: float, a: torch.Tensor,
    omega_c: torch.Tensor, beta: torch.Tensor,
    n: float, e: float, VD: float, rhoD: float,
    s_target: float, dx: float
) -> dict:
    limp = torch.sqrt(eta_xx * tau_imp / (m + 1e-30) + 1e-30)
    lam = 1.0 / limp
    xi = lam * W * 0.5
    lsl = slip_length(eta_xx, a, omega_c, beta)
    s = W / (2.0 * tau_imp * a + 1e-30)
    F = F_xi(xi, lam, lsl)
    Vx_th = gert_alekseev_profile(y, W, eta_xx, tau_imp, m, a, omega_c, beta, VD)
    R_V = (Vx - Vx_th).abs().mean()
    # discrete Navier slip at both edges
    dV_L = (Vx[1] - Vx[0]) / (dx + 1e-30)
    dV_R = (Vx[-1] - Vx[-2]) / (dx + 1e-30)
    R_slip = (Vx[0] - lsl * dV_L).abs() + (Vx[-1] - lsl * dV_R).abs()
    rxx = rho_xx_ga(rhoD, s, F)
    drxy = delta_rho_xy_ga(rhoD, beta, s, F)
    drxy_inf = delta_rho_xy_sat(rhoD, limp, W, eta_xx / (a + 1e-30))
    R_s = torch.relu(s - 1.0)
    scar = R_V + R_slip + (s - s_target).abs() + drxy.abs()
    return {
        "beta": beta,
        "xi": xi,
        "s": s,
        "l_sl": lsl,
        "F": F,
        "rho_xx": rxx,
        "delta_rho_xy": drxy,
        "delta_rho_xy_inf": drxy_inf,
        "R_V": R_V,
        "R_slip": R_slip,
        "R_s": R_s,
        "scar_floor_feed": scar,
        "holographic_DeltaF_trigger": torch.relu((s < 1.0).to(scar.dtype) * drxy.abs() - 1e-8),
        "regime": "hydro-rough-min" if (s < 1.0 and xi < 1.0) else ("Ohmic" if xi > 3.0 else "hydro-smooth"),
        "Qin_compatible": Vx,
    }
```
