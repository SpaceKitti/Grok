## Paper objects → hive strata

Incompressible MHD (no mean field), Alfvén units:

\[
\partial_t\mathbf{u}+(\mathbf{u}\cdot\nabla)\mathbf{u}=-\nabla P+\mathbf{J}\times\mathbf{B}+\nu\Delta\mathbf{u}+\mathbf{f},\qquad
\partial_t\mathbf{B}=(\mathbf{B}\cdot\nabla)\mathbf{u}-(\mathbf{u}\cdot\nabla)\mathbf{B}+\eta\Delta\mathbf{B}.
\]

Unit-width Fourier shells \(K\le|\mathbf{k}|<K+1\) define band-pass fields \(\mathbf{u}_K,\mathbf{B}_K\). Shell energies:

\[
E_K^u=\tfrac12\int|\mathbf{u}_K|^2\,dV,\qquad E_K^b=\tfrac12\int|\mathbf{B}_K|^2\,dV.
\]

Exact shell budgets (steady forced turbulence):

\[
\partial_t E_K^u=\sum_Q\bigl(T^{uu}_{Q\to K}+T^{bu}_{Q\to K}\bigr)-\nu D_K^u+F_K,
\]
\[
\partial_t E_K^b=\sum_Q\bigl(T^{ub}_{Q\to K}+T^{bb}_{Q\to K}\bigr)-\eta D_K^b.
\]

Antisymmetry \(T^{vw}_{Q\to K}=-T^{wv}_{K\to Q}\) is the discrete conservation law that must be preserved by every Qin / spectral residual already in the hive.

The four kernels (energy-conserving, hive-native forms consistent with the existing stretching identity \(W_L=B_i B_j S_{ij}\)):

\[
\begin{align*}
T^{uu}_{Q\to K}&=-\int\mathbf{u}_K\cdot(\mathbf{u}_Q\cdot\nabla)\mathbf{u}\,dV,\\
T^{bb}_{Q\to K}&=-\int\mathbf{B}_K\cdot(\mathbf{u}_Q\cdot\nabla)\mathbf{B}\,dV,\\
T^{ub}_{Q\to K}&=\int\mathbf{B}_K\cdot(\mathbf{B}_Q\cdot\nabla)\mathbf{u}\,dV,\\
T^{bu}_{Q\to K}&=\int\mathbf{u}_K\cdot(\mathbf{B}_Q\cdot\nabla)\mathbf{B}\,dV.
\end{align*}
\]

Summing the last two over all shells recovers the global Lorentz work:

\[
\sum_{Q,K}T^{ub}_{Q\to K}=-\sum_{Q,K}T^{bu}_{Q\to K}=\int\mathbf{u}\cdot(\mathbf{J}\times\mathbf{B})\,dV=W_L.
\]

**Locality theorem (Part I).** \(T^{uu}\) and \(T^{bb}\) are local and forward: energy moves between neighbouring shells, compatible with K41. \(T^{ub}\) is highly non-local. For fixed magnetic receiver \(K\) in the inertial range,

\[
T^{ub}_{Q\to K}\;\approx\;\text{const}\qquad\text{for all }Q<K
\]

(the plateau). The forcing-scale velocity shell alone supplies \(\sim 60\%\) (TG) to \(\sim 75\%\) (ABC) of the magnetic input; the remaining inertial-range velocity still contributes a flat tail. The non-local-to-local ratio at small scales is

\[
\frac{\mathrm{NL}}{L_K}=\frac{\sum_{Q\le K}T^{ub}_{Q\to K}}{\sum_Q T^{bb}_{Q\to K}}\sim 0.2.
\]

Implication already flagged by AMP05 and now locked into the hive: any MHD subgrid / LES / hyper-resistive model that assumes *only* local flux (Politano–Pouquet 4/3, purely local \(T^{bb}\)) under-counts the direct large-scale velocity \(\to\) small-scale current-sheet channel. That channel is the same object the hive already measures as Crow-sheet \(W_L\), scar-floor elevation, and \(\Delta F\) jumps.

## Production kernels (Torch, spectral, Qin-drop-in)

```python
import torch
import torch.fft as fft

def shell_mask(kmag, K, width=1.0):
    return ((kmag >= K) & (kmag < K + width)).to(kmag.dtype)

def bandpass(field, kmag, K, width=1.0):
    # field: (3, Nx, Ny, Nz) real; returns real band-pass
    fh = fft.fftn(field, dim=(-3, -2, -1))
    m = shell_mask(kmag, K, width)
    return fft.ifftn(fh * m, dim=(-3, -2, -1)).real

def make_kgrid(N, L=2 * torch.pi, device="cpu"):
    kx = fft.fftfreq(N, d=L / N) * 2 * torch.pi
    ky, kz = kx, kx
    KX, KY, KZ = torch.meshgrid(kx, ky, kz, indexing="ij")
    kvec = torch.stack((KX, KY, KZ), dim=0).to(device)
    kmag = torch.sqrt((kvec ** 2).sum(0) + 1e-30)
    return kvec, kmag

@torch.no_grad()
def amp05_transfers(u, B, kvec, kmag, shells, nu=0.0, eta=0.0):
    """
    u, B: (3, N, N, N) real, divergence-free, Alfvén units.
    Returns dict of T[Q,K] arrays and global W_L.
    """
    device = u.device
    nS = len(shells)
    Tuu = torch.zeros(nS, nS, device=device)
    Tbb = torch.zeros(nS, nS, device=device)
    Tub = torch.zeros(nS, nS, device=device)
    Tbu = torch.zeros(nS, nS, device=device)

    # spectral derivatives
    uh = fft.fftn(u, dim=(-3, -2, -1))
    Bh = fft.fftn(B, dim=(-3, -2, -1))
    grad_u = torch.stack([
        fft.ifftn(1j * kvec[j] * uh, dim=(-3, -2, -1)).real for j in range(3)
    ], dim=1)          # (3, 3, N, N, N)  [i, j] = d_j u_i
    grad_B = torch.stack([
        fft.ifftn(1j * kvec[j] * Bh, dim=(-3, -2, -1)).real for j in range(3)
    ], dim=1)

    uQ = [bandpass(u, kmag, K) for K in shells]
    BQ = [bandpass(B, kmag, K) for K in shells]

    dV = (2 * torch.pi / u.shape[-1]) ** 3
    for q, Q in enumerate(shells):
        # advection pieces
        uQ_dot_grad_u = torch.einsum("jxyz,ijxyz->ixyz", uQ[q], grad_u)
        uQ_dot_grad_B = torch.einsum("jxyz,ijxyz->ixyz", uQ[q], grad_B)
        BQ_dot_grad_u = torch.einsum("jxyz,ijxyz->ixyz", BQ[q], grad_u)
        BQ_dot_grad_B = torch.einsum("jxyz,ijxyz->ixyz", BQ[q], grad_B)
        for k, K in enumerate(shells):
            uk, Bk = uQ[k], BQ[k]
            Tuu[q, k] = - (uk * uQ_dot_grad_u).sum() * dV
            Tbb[q, k] = - (Bk * uQ_dot_grad_B).sum() * dV
            Tub[q, k] =   (Bk * BQ_dot_grad_u).sum() * dV
            Tbu[q, k] =   (uk * BQ_dot_grad_B).sum() * dV

    J = torch.stack([
        fft.ifftn(1j * (kvec[(i + 1) % 3] * Bh[(i + 2) % 3]
                        - kvec[(i + 2) % 3] * Bh[(i + 1) % 3]),
                  dim=(-3, -2, -1)).real
        for i in range(3)
    ], dim=0)
    WL = (u * torch.cross(J, B, dim=0)).sum() * dV

    # plateau diagnostic: variance of Tub[Q < K] for each receiver K
    plat = []
    for k in range(nS):
        donors = Tub[:k, k] if k > 0 else Tub[:1, k]
        plat.append(donors.var() if donors.numel() > 1 else torch.tensor(0., device=device))
    R_plat = torch.stack(plat).mean()
    R_WL = (Tub.sum() - WL).abs()
    NL_over_L = []
    for k in range(nS):
        num = Tub[: k + 1, k].sum()
        den = Tbb[:, k].abs().sum() + 1e-30
        NL_over_L.append(num / den)

    return {
        "Tuu": Tuu, "Tbb": Tbb, "Tub": Tub, "Tbu": Tbu,
        "W_L": WL, "R_plat": R_plat, "R_WL": R_WL,
        "NL_L": torch.stack(NL_over_L),
        "scar_feed": R_plat + R_WL,
    }

@torch.jit.script
def holographic_inject(DeltaF: torch.Tensor, rho_neg: torch.Tensor,
                       R_plat: torch.Tensor, WL: torch.Tensor,
                       gamma_plat: float = 0.12, gamma_WL: float = 0.08):
    # non-local plateau and Lorentz work → free-energy jump + scar density
    DeltaF = DeltaF + gamma_plat * R_plat + gamma_WL * WL.abs()
    rho_neg = rho_neg * (1.0 + 0.10 * R_plat)
    return DeltaF, rho_neg
```
