\[

=\star_h^{-1}d_h\star_h d_h\mathbf{J}_h+d_h\star_h^{-1}d_h\star_h\mathbf{J}_h.

Because \(\mathbf{J}_h\) is already a discrete curl, the gradient-divergence piece is spectrally small; the dominant term is the curl-curl Hodge block. Commuting projectors \(\Pi^i\) guarantee
\[

def qin_hodge_laplacian_1form(

def hyper_weighted_volterra(
    lambda_shear: torch.Tensor,
    eps_H: torch.Tensor,
    Sigma_H: torch.Tensor,
    Sigma0: torch.Tensor,
    s: int,
    dv: float,
    alpha: float = 1.0,
    alpha_ln: float = 1.0
) -> torch.Tensor:
    cum = torch.cumsum(lambda_shear * dv, dim=0)
    delta = cum.unsqueeze(1) - cum.unsqueeze(0)
    mask = torch.tril(torch.ones_like(delta))

        1.0
        + alpha * eps_H.abs().unsqueeze(0)
        + alpha_ln * (Sigma_H - Sigma0).abs().unsqueeze(0)

    return torch.exp(-(s + 1) * delta) * mask * weight
