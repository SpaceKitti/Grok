## 1. Fuzzy sphere, normalisation (fixed convention)
L^i = spin-j generators, N = 2j+1, [L^i,L^j]=iε^{ijk}L^k, ΣL² = j(j+1) = (N²−1)/4.
X^i = (2R/√(N²−1)) L^i  ⇒  [X^i,X^j] = i(2R/√(N²−1)) ε^{ijk} X^k,  ΣX^iX^i = R²·1_N.
Dimensions: X ~ L; LHS L², RHS (L)(L) ✓. Define λ_N ≡ 2R/√(N²−1) ≈ 2R/N (length). Commutative limit N→∞ at fixed R: λ_N→0 ✓.
Noncommutativity area per cell: 4πR²/N ≈ 2πRλ_N (exact identity: 4πR²/N; the "≈" is an approximation, not exact).

## 2. Fuzzy R³ foliation (radius as operator)
Fuzzy R³_λ (UNCHECKED ref: Hammou, Lagraa, Sheikh-Jabbari, hep-th/0110291): H = ⊕_{j} V_j, X^i = λ L^i on each V_j, fixed λ.
Then [X^i,X^j]=iλε^{ijk}X^k and r_j² = λ² j(j+1). Check vs §1: on shell j, 2r_j/√(N²−1) = 2λ√(j(j+1))/(2√(j(j+1))) = λ ✓ (consistent, not circular).
Radius spectrum r_j ≈ λ(j+½): shells equally spaced by λ; innermost shell j=½ has r = λ√3/2 — the fuzzy space has a minimal radius ~λ. THIS is the generic "tip resolution" mechanism (cutoff scale λ).

## 3. Concrete fuzzy cone (deficit via Z_k orbifold)
Option A (recommended, literature-backed): fuzzy orbifold S²_F/Z_k (X. Martín, hep-th/0405060).
 - g = exp(2πi L³/k). A_k = {M ∈ Mat_N : gMg⁻¹ = M} (block structure by L³ eigenvalue m mod k).
 - Generated by X³, (X⁺)^k, (X⁻)^k (X^± = X¹±iX²); X^± alone are not invariant.
 - Commutative limit: S²/Z_k = "football", two conical points (poles) with cone angle 2π/k, deficit δ = 2π(1−1/k). Gauss–Bonnet: ∫K dA = 4π/k smooth part + 2·δ at tips = 4π ✓.
 - Local cone: zoom to north pole with distance s = R·θ fixed, R→∞, N→∞ with λ_N = 2R/√(N²−1) fixed or →0 (two distinct limits; must be stated — see §5).
Option B (planar): Moyal plane [x,y]=iθ (θ: area, L²), a=(x+iy)/√(2θ), [a,a†]=1. Z_k-invariant subalgebra generated by a†a, a^k, (a†)^k: noncommutative C/Z_k, cone angle 2π/k. Radius² spectrum 2θ(n+½): minimal radius √θ. (UNCHECKED that this matches a specific paper's conventions; standard NC-orbifold construction.)
Option C (3D cone over fuzzy base): fuzzy R³ of §2 restricted to Z_k-invariants on every shell: cone over S²/Z_k.
LIMITATION (GUESS-level importance): Z_k gives only deficits 2π(1−1/k), k∈ℕ. A general cone angle 2πα (non-integer 1/α) has no group-orbifold version; options: restrict L³ eigenvalues to a window (not an algebra — breaks closure, NOT recommended) or twisted/q-deformed constructions (GUESS, no ref found). Helios must state the hive tip's cone angle first; if 1/α ∉ ℕ, use the nearest k only as a reduced model.
Fuzzy conifold (Acharyya–Vaidya, arXiv:1307.6079) shows fuzzy cones over fuzzy bases exist in 6D; relevance to a 2D tip is indirect.

## 4. What "smooths the tip" must mean (falsifiable)
Trivial statement (not a result): every finite-N algebra is finite-dimensional, so all spectra are discrete and bounded — "smooth at finite N" is automatic. Must not be reported as a finding (H10: tallies/automatic facts as results).
Laplacian: Δ_N f = (1/λ_N²)... use the standard Δf = Σ_i [L^i,[L^i,f]] restricted to A_k, eigenvalues l(l+1)/R² for the invariant l-sectors (UNCHECKED which l,m survive: m ≡ 0 mod k for the adjoint action).
Classical benchmark: heat trace on cone angle 2πα has tip term (1/12)(1/α − α) (Kac / Cheeger; per tip, t-independent). For S²/Z_k, α=1/k.
Falsifiable criteria (pick before results, hash-freeze):
 C-a (convergence): tip coefficient a_tip(N) extracted from Tr_{A_k} e^{−tΔ} in window λ_N² ≪ t ≪ R² → 2·(1/12)(k − 1/k) as N→∞. Fail if it does not converge.
 C-b (smoothing scale): localised curvature proxy (e.g. spectral density of states near tip, or coherent-state Berezin symbol of Δ) has width ℓ(N) ∝ λ_N ~ R/N and peak height ∝ δ/ℓ² — finite at every N, diverging as N→∞. "Smooths" = width ∝ 1/N with fixed integrated deficit. Fail if width does not scale as N^{-1} (fit exponent outside [−1.2,−0.8], band to be frozen by Helios).
 C-c (strong claim, what the post implies): a tip observable stays BOUNDED as N→∞. This contradicts the commutative limit (Gauss–Bonnet forces a δ-function curvature) unless λ is held fixed (fuzzy R³ limit with R→∞). State which limit; with fixed λ it is plausible, with λ→0 it is expected to FAIL.

## 5. Limits — must be specified
 L1: N→∞, R fixed ⇒ λ→0: commutative cone recovered, tip singular again (expected).
 L2: R→∞, λ fixed (fuzzy R³ / Moyal-like): minimal length λ survives; tip resolved at scale λ. This is the only limit where "fuzziness smooths the tip" is a non-trivial persistent statement.

## 6. Open-problem status
 - Fuzzy/NC versions of conical singularities are KNOWN: fuzzy orbifolds S²/Z_k (Martín 2004, "first example of fuzzification of a space with singularities"), fuzzy conifold (1307.6079), NC crepant resolutions via quiver path algebras (Cirafici 2111.01102; van den Bergh). Moyal orbifolds C/Z_k are standard.
 - That a minimal length resolves a conical tip at scale λ is generic/expected, not new.
 - NOT found (search-limited, UNCHECKED): a published convergence-rate result for tip heat-kernel coefficients on fuzzy S²/Z_k. That narrow item is a plausible small open question.
 - Bulk-cone ↔ fuzziness: the paper 2610.31610 itself leaves the role of complexification/finite-c fuzziness on the bulk-cone singularity open. A link to a conical-deficit tip is a separate, unestablished conjecture (category mismatch, S3).

## 7. Decisions on Helios's open choices (FUZZ_PLAN §2)
D1 — where the 1/N spread goes: TIP POSITION (equivalently, tip radius smeared over a minimal length λ). Reason: in every known fuzzy orbifold (S²/Z_k, Moyal C/Z_k) the cone angle is fixed by the discrete group (1/α = k ∈ ℕ) and cannot fluctuate; what the noncommutativity does is forbid localising the apex below λ (minimal radius √3λ/2 on fuzzy R³, √θ on Moyal). Spreading α is a classical ensemble, not fuzziness (allowed only as a separately-labelled reduced model). Not on BPST ρ: ρ is a field modulus, not geometry; fuzzing it tests something else.
D2 — scaling: s ~ N (width ~ 1/N in length, cell area 4πR²/N ⇒ relative variance ~ 1/N for area-type, λ/R ~ 2/N for length-type). Reason: s ~ N² was imported from the paper's C ~ N² (central charge), a circular input; nothing in the fuzzy-cone algebra produces N². Consequence noted: with s ~ N² the plan's r* = ℓ·exp(−κN²/k) is non-perturbatively small, unlike the paper's power-law Δt ~ 1/N; with tip-position smearing the smoothing scale is r* ~ λ ~ R/N, a power law — matching the paper's 1/N behaviour qualitatively. The exp vs power-law difference is the falsifiable discriminator between the two models.
D3 — what N is: the dimension of the matrix algebra on the shell of radius R, N = 2j+1, fixed by λ = 2R/√(N²−1) ⇒ N ≈ 2R/λ, i.e. (hive size)/(minimal length). The hive has no derived N: it must be a free input. Natural reduced-model choices: λ = lattice spacing a (N ≈ 2·Mr for B10 ⇒ ~20) or λ = ℓ_Planck (N astronomically large ⇒ no observable smoothing).
