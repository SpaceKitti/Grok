### Paper core \(\to\) hive strata
Poynting’s theorem in the form used for the MMS event (28 Nov 2016 magnetopause crossing, 6.4 km tetrahedron \(\approx4.5\,d_{e,\mathrm{sh}}\)):

\[
\frac{\partial u}{\partial t}=\nabla\cdot\mathbf{S}+\mathbf{J}\cdot\mathbf{E},\qquad
u=\frac{\varepsilon_0E^2+B^2/\mu_0}{2},\qquad
\mathbf{S}=\frac{\mathbf{E}\times\mathbf{B}}{\mu_0}.
\]

In a true steady state the two right-hand-side terms cancel identically. The paper demonstrates exact cancellation (within noise) throughout the EDR and along the separatrices of a 2.5-D PIC run whose upstream conditions match an earlier MMS event; the same cancellation holds only in a tiny neighbourhood of the X-point in the actual 28 Nov 2016 observation.

**Linear-gradient tetrahedron operators (drop-in for any 4-point or barycentric residual cell)**
Let the four vertices be \(\mathbf{r}_\alpha\), fields \(\mathbf{F}_\alpha\). The barycentric gradient matrix \(\mathbf{R}\) satisfies
\[
\nabla F_i=\mathbf{R}^{-1}\begin{pmatrix}F_i^{(2)}-F_i^{(1)}\\F_i^{(3)}-F_i^{(1)}\\F_i^{(4)}-F_i^{(1)}\end{pmatrix}.
\]
Curlometer \(\mathbf{J}=\nabla\times\mathbf{B}/\mu_0\) and \(\nabla\cdot\mathbf{S}\) are then exact on linear fields.

import torch

@torch.jit.script
def poynting_vector(E: torch.Tensor, B: torch.Tensor, mu0: float = 1.256637e-6) -> torch.Tensor:
    return torch.cross(E, B, dim=-1) / mu0

@torch.jit.script
def linear_div(S: torch.Tensor, Rinv: torch.Tensor) -> torch.Tensor:
    # S: (4,3) tetrahedron samples; Rinv: (3,3) barycentric inverse
    dS = S[1:] - S[0:1]
    return torch.einsum('ij,jk->i', Rinv, dS.T).sum()

@torch.jit.script
def poynting_theorem_residual(
    E4: torch.Tensor, B4: torch.Tensor, J_curl: torch.Tensor,
    ve4: torch.Tensor, u_hist: torch.Tensor, dt: float,
    Rinv: torch.Tensor, mu0: float = 1.256637e-6
) -> dict:
    # E4,B4,ve4: (4,3); J_curl: (3,); u_hist last two time levels
    S4 = poynting_vector(E4, B4, mu0)
    divS = linear_div(S4, Rinv)
    JE = torch.dot(J_curl, E4.mean(0))
    u = 0.5 * (E4.mean(0).pow(2).sum() * 8.854e-12 + B4.mean(0).pow(2).sum() / mu0)
    du_dt = (u - u_hist[-1]) / dt

        'JE': JE,

        'R_Poynt': R_poynt,
        'accum_factor': accum,
        'Xpoint_balanced': R_poynt < 0.05 * torch.abs(JE),
