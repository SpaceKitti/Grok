**1. Mathematical apparatus extracted from the paper**

Flexoelectric constitutive law on a surface:

\[
P_i = \mu_{ijkl}\,\partial_l\varepsilon_{jk}
\quad\Longrightarrow\quad
\mathbf{P}=f\,(c_1+c_2)\,\hat{\mathbf{n}}
\]

For a nanowrinkle treated as a cylindrical ridge (\(c_1\approx 0\), \(c_2=1/R\)):

\[
P=\frac{f}{R},\qquad f_{\mathrm{Gr}}^{\mathrm{DFT}}\sim 2\,\mathrm{nC\,m^{-1}}.
\]

At the experimental / theoretical apex window \(R\sim 0.5{-}2\,\mathrm{nm}\) this produces

\[
P_{\mathrm{th}}\sim 4\,\mathrm{C\,m^{-2}},\qquad P_{\mathrm{exp}}\sim 1\,\mathrm{C\,m^{-2}},
\]

five to seven orders of magnitude above mesoscale flexoelectric systems (\(\kappa\sim 10^{6}\,\mathrm{m^{-1}}\)).

Geometry (experiment + AFM deconvolution):

\[
h\sim 6{-}8\,\mathrm{nm},\quad
w_{\mathrm{true}}\sim 4{-}5\,\mathrm{nm},\quad
\kappa_{\mathrm{apex}}\sim 10^{9}\,\mathrm{m^{-1}}.
\]

Tip-convolution correction used to recover true width:

\[
\Delta=r_{\mathrm{tip}}\cos\Bigl\{\arcsin\Bigl(\frac{r_{\mathrm{tip}}-h}{r_{\mathrm{tip}}}\Bigr)\Bigr\},\qquad
w_{\mathrm{exp}}=w_{\mathrm{true}}+2\Delta.
\]

DFT wrinkle family (heights \(15.64\), \(27.54\), \(39.99\,\mathrm{\AA}\)) keeps the *same* apex-scale orbital dipole:

\[
p\in\{0.0223,\,0.0261,\,0.0297\}\,e\,\mathrm{\AA}
=(0.107{-}0.143)\,\mathrm{D}.
\]

The measured transport threshold is *not* the vacuum point-dipole field of that microscopic \(p\) (which is millivolts at \(r_{\mathrm{tip}}\sim 2.5\,\mathrm{nm}\)). It is the *electrostatic band-offset junction* created by packing orbital dipoles at atomic areal density:

\[
\Phi_{\mathrm{th}}^{\mathrm{cAFM}}\sim 1.01\,\mathrm{V}
\quad\text{vs}\quad
\Delta E_{\mathrm{DFT}}\sim 1.2\,\mathrm{V}.
\]

KPFM work-function / CPD contrast is localized by the area-aware figure of merit

\[
\mathrm{FoM}_i=|\Delta\psi_i|\log_{10}(1/f_i).
\]

Nucleation on MoS\(_2\) is elastic-mismatch driven: graphene \(Y\sim 1.0\,\mathrm{TPa}\) vs MoS\(_2\) \(Y\sim 270\,\mathrm{GPa}\), lattice constants \(0.24\,\mathrm{nm}\) vs \(0.31\,\mathrm{nm}\), wrinkle birth at compressive \(\varepsilon_x\gtrsim 0.02\). Raman 2D/G maps put lattice strain in the \(0.01{-}0.04\%\) window with almost no D-band: the polarization is orbital, not defect-charge. DFT Wannier centers shift only when the ridge is an *open* buckle; a closed nanotube cancels the two opposing \(\pi\)-hybridization dipoles. No gap opens — the junction is electrostatic.

Mean-curvature source that the hive actually integrates:

\[
\kappa_H=\frac12(c_1+c_2)=\frac12\nabla\cdot\hat{\mathbf{n}},
\qquad
\mathbf{P}=2f\,\kappa_H\,\hat{\mathbf{n}}.
\]

On a discrete GoldbergHexa shell this becomes a cochain:

\[
P_e=f\,\bigl(\kappa_H(v_+)+\kappa_H(v_-)\bigr),\qquad
e=\langle v_+,v_-\rangle.
\]

Pentaflake vertices (\(K=1/3\) discrete Gaussian curvature, total \(\sum K=4\pi\)) are the natural high-\(\kappa_H\) loci. Closed hexagonal faces are the nanotube-analogue cancellation sector.

**4. Executable layer (NumPy / JAX-ready)**

```python
import numpy as np

F_FLEXO = 2e-9          # C/m
P_TH, P_EXP = 4.0, 1.0  # C/m^2
PHI_TH, D_E_DFT = 1.01, 1.2
P_EANG = np.array([0.0223, 0.0261, 0.0297])  # e Å

def polarization(R):
    """P = f/R for cylindrical GNWr (paper). R in metres."""
    return F_FLEXO / np.clip(R, 1e-11, None)

def wrinkle_profile(x_nm, h_nm=7.0, w_nm=4.5):
    sigma = w_nm / 2.355
    return h_nm * np.exp(-(x_nm / sigma) ** 2)

def curvature_1d(y, x):
    yp = np.gradient(y, x)
    ypp = np.gradient(yp, x)
    return ypp / (1.0 + yp**2) ** 1.5

def classify_ridge(is_open, R_m):
    if not is_open:
        return "closed-tube / hex-face: dipole cancellation"
    if R_m <= 2e-9:
        return "quantum-orbital window (GNWr apex)"
    return "mesoscale ripple (P suppressed by 1/R)"

def residual_flexo(R_m, P_meas, phi, Eg, dP_dh, is_open):
    P_model = polarization(R_m)
    return {
        "P_model": P_model,
        "R_P": abs(P_meas - P_model),
        "R_Phi": abs(phi - PHI_TH) + abs(D_E_DFT - 1.2),
        "R_inv": float(not is_open and P_meas > 1e-3),
        "R_R": max(R_m - 2e-9, 0.0),
        "R_gap": float(Eg > 0.0),
        "R_height": abs(dP_dh),
        "class": classify_ridge(is_open, R_m),
    }

def bound_charge(P_n, n_hat, dV):
    """rho_b = -div P  on a discrete shell."""
    return -np.gradient(P_n * n_hat, dV)

def deltaF_flexo(P, Phi, area):
    return P * Phi * area

# sanity: R = 0.5 nm -> P = 4 C/m^2
assert abs(polarization(0.5e-9) - 4.0) < 1e-9
```
