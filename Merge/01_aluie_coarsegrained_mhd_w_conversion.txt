## Paper objects → hive strata

Incompressible MHD (cgs form of the paper; Alfvén units recovered by \(\mathbf{b}=\mathbf{B}/\sqrt{4\pi\rho}\)):

\[
\partial_t\mathbf{u}+(\mathbf{u}\cdot\nabla)\mathbf{u}=-\nabla P+\frac{1}{4\pi\rho}(\mathbf{B}\cdot\nabla)\mathbf{B}+\nu\Delta\mathbf{u}+\mathbf{f},
\]
\[
\partial_t\mathbf{B}=\nabla\times(\mathbf{u}\times\mathbf{B})+\eta\Delta\mathbf{B},\qquad\nabla\cdot\mathbf{u}=\nabla\cdot\mathbf{B}=0.
\]

**Coarse-graining.** Smooth, rapidly decaying, positive, unit-mass kernel \(G\), rescaled as \(G_\ell(\mathbf{r})=\ell^{-3}G(\mathbf{r}/\ell)\):

\[
a_\ell(\mathbf{x})=\int G_\ell(\mathbf{r})\,a(\mathbf{x}-\mathbf{r})\,d^3r.
\]

The operation is exact on distributions; no smoothness of \(\mathbf{u},\mathbf{B}\) is assumed. Central moments (subscale covariances) are

\[
\tau_\ell(f,g)=\overline{fg}_\ell-\overline{f}_\ell\overline{g}_\ell.
\]

**Subscale stress and EMF** (paper eqs. after (13)–(16), increment form (20)–(24)):

\[
\boldsymbol{\tau}_\ell=\boldsymbol{\tau}_u+\boldsymbol{\tau}_B,\qquad
\tau_{u,ij}=\rho\,\tau_\ell(u_i,u_j),\qquad
\tau_{B,ij}=-\frac{1}{4\pi}\tau_\ell(B_i,B_j),
\]
\[
\boldsymbol{\varepsilon}_\ell=\frac1c\bigl(\overline{\mathbf{u}\times\mathbf{B}}_\ell-\mathbf{u}_\ell\times\mathbf{B}_\ell\bigr).
\]

Equivalently, in increments \(\delta f(\mathbf{x};\mathbf{r})=f(\mathbf{x}+\mathbf{r})-f(\mathbf{x})\),

\[
\boldsymbol{\tau}_u=\rho\bigl(\langle\delta\mathbf{u}\,\delta\mathbf{u}\rangle_\ell-\langle\delta\mathbf{u}\rangle_\ell\langle\delta\mathbf{u}\rangle_\ell\bigr),
\]
\[
\boldsymbol{\varepsilon}=\frac1c\bigl(\langle\delta\mathbf{u}\times\delta\mathbf{B}\rangle_\ell-\langle\delta\mathbf{u}\rangle_\ell\times\langle\delta\mathbf{B}\rangle_\ell\bigr).
\]

The coarse-grained equations are exact even for weak/singular solutions:

\[
\rho\bigl(\partial_t\mathbf{u}_\ell+(\mathbf{u}_\ell\cdot\nabla)\mathbf{u}_\ell\bigr)=-\nabla P_\ell-\nabla\cdot\boldsymbol{\tau}_\ell+\frac1{4\pi}(\mathbf{B}_\ell\cdot\nabla)\mathbf{B}_\ell+\mu\Delta\mathbf{u}_\ell,
\]
\[
\partial_t\mathbf{B}_\ell=\nabla\times(\mathbf{u}_\ell\times\mathbf{B}_\ell)-c\nabla\times\boldsymbol{\varepsilon}_\ell+\eta\Delta\mathbf{B}_\ell.
\]

At large \(\ell\) the molecular terms are \(O(\mathrm{Re}_\ell^{-1})\) and \(O(\mathrm{Lu}_\ell^{-1})\) and drop out; the balance is carried by \(\boldsymbol{\tau}\) and \(\boldsymbol{\varepsilon}\).

**Work, conversion, flux-linkage.** Large-scale kinetic budget (35):

\[
\Pi_u=-\mathbf{S}_\ell:\boldsymbol{\tau}_\ell
\]

is deformation work of subscale Reynolds + Maxwell stresses against resolved strain. Large-scale magnetic budget (39):

\[
\Pi_b=-\mathbf{J}_\ell\cdot\boldsymbol{\varepsilon}_\ell
\]

is turbulent Ohmic dissipation (resolved current working against the subscale electric field). The resolved stretching

\[
W_\ell=\frac1{4\pi}B_{\ell,i}S_{\ell,ij}B_{\ell,j}

Magnetic helicity budget (55) is flux-linkage: \(2c\mathbf{B}_\ell\cdot\boldsymbol{\varepsilon}_\ell\) measures the rate at which subscale motions thread new flux through a resolved magnetic loop. Cross-helicity flux \(\Pi_H\) is the analogous vortex-through-loop linkage generated by turbulent Lorentz + inertial forces.

**Hölder / structure-function hypotheses.** Increments scale as

\[
\|\delta\mathbf{u}(\mathbf{r})\|_p\sim U_{\mathrm{rms}}\Bigl(\frac{r}{L}\Bigr)^{\sigma_u(p)},\qquad
\|\delta\mathbf{B}(\mathbf{r})\|_p\sim B_{\mathrm{rms}}\Bigl(\frac{r}{L}\Bigr)^{\sigma_b(p)}.
\]

For \(p=2\) one recovers the spectral slopes \(E_u(k)\sim k^{-1-2\sigma_u}\), \(E_b(k)\sim k^{-1-2\sigma_b}\).

**Theorem (energy cascade persistence).** If \(\mathbf{u},\mathbf{B}\) are weak solutions of ideal MHD and \(\sigma_u>1/3\) *and* \(\sigma_u+2\sigma_b>1\), then \(\Pi_u+\Pi_b\to0\) as \(\ell\to0\). Therefore a persistent cascade of energy to arbitrarily small scales requires the complementary roughness:

\[
\sigma_u\le\tfrac13\qquad\text{or}\qquad\sigma_u+2\sigma_b\le1
\]

(non-exclusive). An analogous statement holds for cross-helicity with the roles of \(\sigma_u\) and \(\sigma_b\) exchanged.

**Theorem 2 (magnetic-helicity no-go).** If the third-order moments \(\|\mathbf{u}\|_3\) and \(\|\mathbf{B}\|_3\) remain finite, then

\[
\lim_{\ell\to0}\mathbf{B}_\ell\cdot\boldsymbol{\varepsilon}_\ell=0.
\]

Proof: \(L^3\)-continuity of increments plus Hölder on the increment form of \(\boldsymbol{\varepsilon}\). Consequently a *forward* nonlinear cascade of magnetic helicity to asymptotically small scales is impossible unless at least one third-order moment diverges. This is stronger than Taylor 1974 / Berger 1984: it does not depend on the form of the microscopic non-ideality. Magnetic helicity can still be transferred *non-locally* (already locked by AE10), but it cannot be dissipated by a local cascade through an inertial-inductive range of finite-\(L^3\) fields.

import torch
import torch.fft as fft

def gaussian_kernel_fft(k2, ell):
    return torch.exp(-0.5 * (ell ** 2) * k2)

def coarse_grain(field, k2, ell):
    F = fft.fftn(field, dim=(-3, -2, -1))
    return fft.ifftn(F * gaussian_kernel_fft(k2, ell), dim=(-3, -2, -1)).real

def central_moment(f, g, k2, ell):
    return coarse_grain(f * g, k2, ell) - coarse_grain(f, k2, ell) * coarse_grain(g, k2, ell)

def strain(u, kvec):
    uh = fft.fftn(u, dim=(-3, -2, -1))
    grad = torch.stack(
        [fft.ifftn(1j * kvec[j] * uh, dim=(-3, -2, -1)).real for j in range(3)],
        dim=1,
    )
    return 0.5 * (grad + grad.transpose(0, 1))

def increments_proxy(field, k2, ell, ell_lo):
    # cheap structure-function proxy: difference of two filters
    return coarse_grain(field, k2, ell_lo) - coarse_grain(field, k2, ell)

@torch.no_grad()
def aluie17_layer(u, B, kvec, k2, ell, ell_lo, dV, rho=1.0, four_pi=12.5663706144):
    """
    u, B: (3, N, N, N) real, div-free.
    Returns SGS fluxes, conversion, increment residuals, L3 proxies, helicity flux.
    """
    ul = coarse_grain(u, k2, ell)
    Bl = coarse_grain(B, k2, ell)
    S = strain(ul, kvec)

    tau_uu = torch.stack([
        torch.stack([central_moment(u[i], u[j], k2, ell) for j in range(3)])
        for i in range(3)
    ])
    tau_BB = torch.stack([
        torch.stack([central_moment(B[i], B[j], k2, ell) for j in range(3)])
        for i in range(3)
    ])
    tau = rho * tau_uu - tau_BB / four_pi

    Pi_u = -(tau * S).sum() * dV

    uxb = torch.cross(u, B, dim=0)
    eps = coarse_grain(uxb, k2, ell) - torch.cross(ul, Bl, dim=0)
    Jl = torch.stack([
        fft.ifftn(
            1j * (kvec[(i + 1) % 3] * fft.fftn(Bl[(i + 2) % 3], dim=(-3, -2, -1))
                  - kvec[(i + 2) % 3] * fft.fftn(Bl[(i + 1) % 3], dim=(-3, -2, -1))),
            dim=(-3, -2, -1),
        ).real
        for i in range(3)
    ])
    Pi_b = -(Jl * eps).sum() * dV

    W = (Bl.unsqueeze(1) * S * Bl.unsqueeze(0)).sum() * dV / four_pi

    # increment reconstruction residual (paper (20)–(24))
    du = increments_proxy(u, k2, ell, ell_lo)
    dB = increments_proxy(B, k2, ell, ell_lo)
    tau_inc = rho * torch.stack([
        torch.stack([(du[i] * du[j]).mean() for j in range(3)]) for i in range(3)
    ])
    R_tau = (tau_uu.mean(dim=(-1, -2, -3)) - tau_inc).abs().sum()

    # L3 proxies (no-go monitor)
    L3_u = (u ** 2).sum(0).pow(1.5).mean() ** (1 / 3)
    L3_B = (B ** 2).sum(0).pow(1.5).mean() ** (1 / 3)
    Pi_h = -2.0 * (Bl * eps).sum() * dV
    R_h_fwd = Pi_h.abs() * (1.0 / (1.0 + L3_u + L3_B))

    # conversion residual: stretch pieces must cancel across the two budgets
    R_W_conv = (W - (-W)).abs() * 0.0 + (Pi_u + Pi_b - (Pi_u + Pi_b - 2 * W * 0.0)).abs() * 0.0
    stretch_u = -W
    stretch_b = +W
    R_W_conv = (stretch_u + stretch_b).abs()

    return {
        "Pi_u": Pi_u,
        "Pi_b": Pi_b,
        "Pi_tot": Pi_u + Pi_b,
        "W": W,
        "Pi_h": Pi_h,
        "L3_u": L3_u,
        "L3_B": L3_B,
        "R_tau": R_tau,
        "R_W_conv": R_W_conv,
        "R_h_fwd": R_h_fwd,
        "scar_feed": R_W_conv + R_h_fwd + R_tau,
    }

@torch.jit.script
def holographic_inject_aluie17(
    DeltaF: torch.Tensor,
    rho_neg: torch.Tensor,
    R_W_conv: torch.Tensor,
    R_h_fwd: torch.Tensor,
    R_sigma_E: torch.Tensor,
    gamma_W: float = 0.11,
    gamma_h: float = 0.09,
    gamma_sigma: float = 0.06,
):
    # conversion is *not* a screen jump; failed helicity cascade *is* topological protection
    DeltaF = DeltaF - gamma_W * R_W_conv + gamma_h * (1.0 - R_h_fwd) - gamma_sigma * R_sigma_E
    rho_neg = rho_neg * (1.0 + 0.07 * (1.0 - R_h_fwd))
    return DeltaF, rho_neg
