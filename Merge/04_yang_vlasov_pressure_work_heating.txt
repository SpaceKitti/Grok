### Paper core \(\to\) hive strata
Kinetic plasma turbulence spans fluid MHD scales down to sub-electron scales. The Vlasov–Maxwell system is filtered with a compact kernel \(G_\ell(\mathbf{x}-\mathbf{x}')\) of width \(\ell\):

\[
\overline{f}_\alpha(\mathbf{x},\mathbf{v},t)=\int f_\alpha(\mathbf{x}',\mathbf{v},t)\,G_\ell(\mathbf{x}-\mathbf{x}')\,d\mathbf{x}'.
\]

Moments of the filtered Vlasov equation yield exact scale-dependent fluid, thermal, and electromagnetic energy identities. Globally (spatial average, periodic box) the only conversion between fluid-flow energy \(E_{f,\alpha}=\frac12\rho_\alpha|\mathbf{u}_\alpha|^2\) and thermal/random energy \(E_{\mathrm{th},\alpha}\) is the pressure work

\[
\langle\partial_t E_{f,\alpha}\rangle=-\langle\mathbf{P}_\alpha:\nabla\mathbf{u}_\alpha\rangle,\qquad
\langle\partial_t E_{\mathrm{th},\alpha}\rangle=+\langle\mathbf{P}_\alpha:\nabla\mathbf{u}_\alpha\rangle.
\]

The electromagnetic-to-flow channel remains \(\langle\mathbf{j}\cdot\mathbf{E}\rangle\). Thus \(-\mathbf{P}:\nabla\mathbf{u}\) is the collisionless generalization of \(\nu|\mathbf{S}|^2\). Both the subscale energy flux and the pressure work concentrate on intense velocity-gradient structures (current sheets, vortices, strain sheets).

### Key mathematical apparatus (hive-ready)

**Unfiltered species energy split**
\[
E_\alpha=E_{f,\alpha}+E_{\mathrm{th},\alpha},\qquad
E_{f,\alpha}=\tfrac12\rho_\alpha|\mathbf{u}_\alpha|^2,\qquad
E_{\mathrm{th},\alpha}=\tfrac12\mathrm{Tr}\,\mathbf{P}_\alpha.
\]

**Pressure-tensor / velocity-gradient decomposition**
\[
\mathbf{P}=p\,\boldsymbol{\delta}+\boldsymbol{\Pi},\qquad
\nabla\mathbf{u}=\mathbf{S}+\boldsymbol{\Omega}=\mathbf{D}+\tfrac13\theta\,\boldsymbol{\delta}+\boldsymbol{\Omega},
\]
\[
\mathbf{P}:\nabla\mathbf{u}=p\theta+\boldsymbol{\Pi}:\mathbf{D}\qquad\text{(Pi-D term)}.
\]

**Filtered fluid-flow energy equation (Appendix A)**
\[
\partial_t\overline{E}_{f,\alpha}+\nabla\cdot\mathbf{J}_u=\Pi_{uu}+\Phi_{uT}+\Lambda_{ub},
\]
where
- transport \(\mathbf{J}_u=\overline{E}_{f,\alpha}\overline{\mathbf{u}}_\alpha-\overline{\mathbf{P}}_\alpha\cdot\overline{\mathbf{u}}_\alpha\),
- subscale flux \(\Pi_{uu}=\rho_\alpha\boldsymbol{\tau}_{uu}:\nabla\overline{\mathbf{u}}_\alpha-q_\alpha n_\alpha\boldsymbol{\tau}_{uB}\cdot\overline{\mathbf{u}}_\alpha\overline{\mathbf{B}}\),
- pressure work \(\Phi_{uT}=-\overline{\mathbf{P}}_\alpha:\nabla\overline{\mathbf{u}}_\alpha\),
- electromagnetic work \(\Lambda_{ub}=q_\alpha n_\alpha(\overline{\mathbf{E}}\cdot\overline{\mathbf{u}}_\alpha)\).

**Filtered EM energy**
\[
\partial_t\overline{E}_m+\nabla\cdot\Bigl(\frac{\overline{\mathbf{E}}\times\overline{\mathbf{B}}}{4\pi}\Bigr)=-\overline{\mathbf{j}}\cdot\overline{\mathbf{E}}+\sum_\alpha q_\alpha n_\alpha(\overline{\mathbf{E}}\cdot\overline{\mathbf{u}}_\alpha).
\]

**Velocity-gradient invariants used for structure correlation**
\[
Q_D=\tfrac12 D_{ij}D_{ij},\qquad
Q_\omega=\tfrac14|\boldsymbol{\omega}|^2,\qquad
Q_j=\tfrac14|\mathbf{j}|^2.
\]

import torch

@torch.jit.script
def strain_rate(u: torch.Tensor, dx: float) -> torch.Tensor:
    # discrete symmetric gradient on Qin-compatible collocated or staggered grid
    grads = torch.stack(torch.gradient(u, spacing=dx, dim=(-3, -2, -1)), dim=-1)
    return 0.5 * (grads + grads.transpose(-1, -2))

@torch.jit.script
def pressure_work(P: torch.Tensor, grad_u: torch.Tensor) -> torch.Tensor:
    # P : grad u  (last two indices contracted)
    return torch.einsum('...ij,...ij->...', P, grad_u)

@torch.jit.script
def pi_D(Pi: torch.Tensor, D: torch.Tensor) -> torch.Tensor:
    return torch.einsum('...ij,...ij->...', Pi, D)

@torch.jit.script
def filter_box(field: torch.Tensor, ell_cells: int) -> torch.Tensor:
    # separable box / Gaussian kernel of width ell; production: spectral cutoff
    k = ell_cells
    return torch.nn.functional.avg_pool3d(
        field.unsqueeze(0).unsqueeze(0) if field.dim() == 3 else field,
        kernel_size=2 * k + 1, stride=1, padding=k
    ).squeeze()

@torch.jit.script
def yang_filtered_residual(
    rho: torch.Tensor, u: torch.Tensor, P: torch.Tensor,
    E: torch.Tensor, B: torch.Tensor, nq: torch.Tensor,
    ell: int, dx: float

    u_bar = filter_box(u, ell)
    P_bar = filter_box(P, ell)
    E_bar = filter_box(E, ell)
    B_bar = filter_box(B, ell)
