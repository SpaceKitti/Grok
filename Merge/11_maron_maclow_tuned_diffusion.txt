### Paper core \(\to\) hive strata

Finite-difference MHD needs an explicit diffusion operator either for grid-scale stabilization or for physical \(\nu,\eta,\kappa\). The Navier–Stokes / induction residual in the paper is

\[
\partial_t\mathbf{V}
=\mathbf{V}\cdot\nabla\mathbf{V}-\rho^{-1}\nabla P
+\nu_2\nabla^2\mathbf{V}
-\nu_4\nabla^4\mathbf{V}
+\nu_6\nabla^6\mathbf{V}
-\nu_4'(\partial_x^4+\partial_y^4+\partial_z^4)\mathbf{V}
+\nu_6'(\partial_x^6+\partial_y^6+\partial_z^6)\mathbf{V}
-\nu_D\,D[\mathbf{V}].
\]

In Fourier space that is a single symbol

\[
\partial_t\hat{\mathbf{V}}
=-\nu_2 k^2\hat{\mathbf{V}}
-\nu_4 k^4\hat{\mathbf{V}}
-\nu_6 k^6\hat{\mathbf{V}}
-\nu_4'(k_x^4+k_y^4+k_z^4)\hat{\mathbf{V}}
-\nu_6'(k_x^6+k_y^6+k_z^6)\hat{\mathbf{V}}
-\nu_D D(k)\,\hat{\mathbf{V}}.
\]

Wavenumber is normalized so \(k=1\) is Nyquist. A radius-\(S\) centered stencil

\[
D_{\mathrm{st}}[f]_0
=m_0 f_0+\sum_{j=1}^{S}m_j(f_{-j}+f_j)
\]

has the trigonometric symbol

\[
f^{[2]}\;\sim\;
m_0+2\sum_{j=1}^{S}m_j\cos(\pi j k)
\;\equiv\;-D(k).
\]

Constants are annihilated by \(D(0)=0\). The explicit Euler / super-time-step bound is not the Laplacian CFL \(\Delta t=\Delta x^2/(2\nu)\); it is

\[
\Delta t<\frac{1}{\nu_D\max_{k\in[0,1]}D(k)}.
\]

Classical \(\nabla^2,\nabla^4,\nabla^6\) all maximize \(D\) at the grid scale, so the timestep is held hostage by modes the physics does not need to kill. The paper’s move is to force \(D\) to **rise through a chosen diffusion scale \(k_d\) and then flatten**, so \(\max D\) is no larger than the value required at \(k_d\).

Taylor coefficients of the symbol are

\[
D(k)=D_0+D_2 k^2+D_4 k^4+D_6 k^6+\cdots,
\]

\[
D_0=-m_0-2\sum_{q=1}^{S}m_q,
\qquad
D_p=-\frac{2\pi^p}{p!}(-1)^{p/2}\sum_{q=1}^{S}q^p m_q
\quad(p\text{ even}).
\]

For the published radius-3 one-parameter family, normalized so \(D(1/2)=1\),

\[
\begin{aligned}
m_0&=-\tfrac12-\tfrac14 D(1),\\
m_1&=\tfrac18+\tfrac{7}{32}D(1),\\
m_2&=\tfrac14-\tfrac18 D(1),\\
m_3&=-\tfrac18+\tfrac{1}{32}D(1),
\end{aligned}
\qquad
D_4=\pi^4\Bigl(\tfrac18-\frac{D(1)}{16}\Bigr).
\]

Verified identities: \(D(0)=0\), \(D(1/2)=1\), and \(D(1)\) is the free Nyquist height. The paper’s usable window is \(1<D(1)<8\). \(D(1)=8\) recovers the standard sixth-order hyperdiffusivity used in the Pencil code; \(D(1)>8\) drives \(D(k)<0\) on a sub-Nyquist band (anti-diffusion, immediately illegal in the hive). High magnetic Prandtl / Schmidt runs (\(P_m=\nu/\eta\), \(S_c=\nu/\kappa\)) are the other target: physical \(k_d\) then sits **far below** Nyquist, and a Laplacian that keeps climbing to \(k=1\) is a fake viscous tax.

That is exactly why `hyper_kcut=0.5` missed the \(N=48\) sheet. The published family was designed with a *fixed* \(k_d=1/2\). Zhdankin / Huang / Hosking sheets live at

\[
k_{\mathrm{sheet}}\sim\frac{1}{\delta}\sim\frac{S^{1/2}}{L},\qquad
\hat k_d=\frac{k_{\mathrm{sheet}}}{k_{\mathrm{Nyquist}}}=\frac{\Delta x}{\pi\delta}.
\]

On an \(N=48\) box, \(\hat k_d\) is a moving target. Pinning the peak at \(0.5\,k_{\max}\) either (i) damps the inertial range if the sheet is thicker, or (ii) leaves the sheet undamped if the sheet is thinner — the Orion fake leak.

import torch
from typing import Dict, Tuple

@torch.jit.script
def mm09_paper_coeffs(D1: torch.Tensor) -> torch.Tensor:
    # published radius-3 family, D(1/2)=1, D(0)=0
    m0 = -0.5 - 0.25 * D1
    m1 = 0.125 + (7.0 / 32.0) * D1
    m2 = 0.25 - 0.125 * D1
    m3 = -0.125 + (1.0 / 32.0) * D1
    return torch.stack((m0, m1, m2, m3))

@torch.jit.script
def mm09_symbol(k: torch.Tensor, m: torch.Tensor) -> torch.Tensor:
    # k in [0,1], 1 = Nyquist.  D = -(m0 + 2 Σ mj cos(π j k))
    raw = m[0] + 2.0 * (
        m[1] * torch.cos(torch.pi * k)
        + m[2] * torch.cos(2.0 * torch.pi * k)
        + m[3] * torch.cos(3.0 * torch.pi * k)
    )
    return -raw

@torch.jit.script
def k_sheet_hat(L: torch.Tensor, VA: torch.Tensor, eta: torch.Tensor,
                dx: float) -> torch.Tensor:
    # hat k_d = k_sheet / k_Nyquist, k_Nyquist = π/dx
    S = (VA * L / eta.clamp_min(1e-30)).clamp_min(1.0)
    k_sheet = S.sqrt() / L.clamp_min(1e-30)
    k_nyq = torch.pi / max(dx, 1e-30)
    return (k_sheet / k_nyq).clamp(1e-3, 0.95)

def sheet_tuned_coeffs(kd: torch.Tensor, D_nyq: torch.Tensor) -> torch.Tensor:

    s2 = torch.sin(2.0 * torch.pi * kd)
    s3 = torch.sin(3.0 * torch.pi * kd)
    c1 = torch.cos(torch.pi * kd)
    c2 = torch.cos(2.0 * torch.pi * kd)
    c3 = torch.cos(3.0 * torch.pi * kd)

    m0 = -2.0 * (m1 + m2 + m3)

def apply_tuned_diffusion_1d(f: torch.Tensor, m: torch.Tensor) -> torch.Tensor:
    # periodic radius-3 stencil, last axis

    return (
        m[0] * f
        + m[1] * (roll(f, 1, -1) + roll(f, -1, -1))

@torch.jit.script
def apply_tuned_diffusion_3d(f: torch.Tensor, m: torch.Tensor) -> torch.Tensor:

    fz = f.transpose(-1, -3)
    out = out + apply_tuned_diffusion_1d(fz, m).transpose(-1, -3)
